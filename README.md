# 苔岑2D绘图

Vue 3 + Vite 实现的浏览器端 2D 图形编辑器。

```bash
npm install
npm run dev
```

## 功能

- 44 种基本形状、线段、表单、流程、工业、图表、网络、内置动效和自定义动效组件，基础组件包含可设置自动播放和控制器显隐的视频播放器；本地视频在属性栏使用轻量状态显示，网络地址确认后一次加载，避免选中时回填大段 Base64 或编辑时逐键重载媒体
- 直线组件使用自身宽度和高度作为实际长度与粗细，可直接通过属性数值或八方向手柄调整；新建直线默认显示 `2px` 明显轮廓，属性面板独立提供线条颜色、不透明度、实线/虚线/点线、线段长度和间隔，以及轮廓显隐、颜色和宽度。虚线和点线会真正分隔线条主体，并同步显示在编辑、预览和鹰眼中。格式版本 `20` 会自动迁移旧直线及“我的”模板中的直线
- “直线”继续位于“基本形状”，“线段”使用单独分类。线段只能从组件库拖到画布启动，松开位置就是第一个节点；组件库单击或双击均不启动线段。草稿起点显示为比其他节点更大的可拖拽锚点，继续落点前或绘制过程中都可拖动精调；拖动只更新起点，不会新增节点，开启网格吸附时会对齐网格，按住 `Alt` 可临时取消吸附。之后依次单击多个点，每次新落点都会立即与上一个点连接，所有相邻直线最终汇聚为一个普通 `polyline` 组件。画布双击或 `Enter` 完成；`Esc`、右键取消以及 `Backspace` 撤回到零个点都会切回选择工具，完成一条后也会切回选择，起点锚点随草稿一起消失，绘制下一条必须重新从组件库拖拽。线段的“线条样式”沿用直线的控件顺序、术语和视觉风格，支持实线/虚线/点线、分段间隔和轮廓；“线段属性”再提供线宽、独立的 `1–100px` 箭头大小、可分别开启的起点/终点箭头、端点及连接样式，粗线不会再自动放大箭头
- 所有组件（包括直线、旋转节点和组合）无论尺寸均可向画布上、下、左、右部分移出；每条轴按视觉跨度保留操作区，跨度达到 `48px` 时保留 `24px`，不足 `48px` 时保留一半视觉跨度，同时不超过该轴画布尺寸的一半。正式组合固定保留一个真实成员作为可操作锚点，稀疏组合不会因空包围区域跨过画布而整体失去选取入口。选择工具支持空白区域双向框选和 `Ctrl/Cmd/Shift + 左键`增减多选，顶部工具栏、右侧属性栏与右键菜单均可组合或取消组合；多选和组合支持整体移动、缩放、旋转和图层调整。统一选框的四角手柄继续保持原始宽高比，左右边中手柄只拉伸宽度，上下边中手柄只拉伸高度，属性栏的整体宽、高也分别独立修改对应轴，整体 X/Y 只平移而不改变尺寸。组合中的旋转成员会把画布世界横纵倍率映射到自身局部宽高，并按全部成员旋转后的可见边界反求目标组合框；横线与旋转 `90°` 的竖线等相邻成员在反复横向、纵向拉伸和收缩后仍保持连接，恢复原尺寸时位置、尺寸和内容倍率可逆。纯直线组合可压缩到 `0.1px` 高；最大拉伸范围按每个成员的剩余倍率反推，确保成员宽高不超过可保存重载的 `20000px`
- 普通组件缩到 `1 × 1px`、直线缩到 `1 × 0.1px` 后仍保留至少 `24 × 24px` 的屏幕拖动命中区；命中尺寸会反向补偿画布缩放，在最低 `20%` 比例下也可从组件本体外侧重新选中和拖动，极小组件的八个缩放手柄会外移以免覆盖移动入口
- 单个组件或组合可“添加为我的”，保存前可自定义名称；命名输入支持在保持焦点时直接切换中文输入法，中文候选确认不会被 Enter 提前提交。工作空间名称与画布内联文字使用相同的中文组合输入保护，同时保留 `Ctrl+S` 等全局快捷键。“我的”卡片由模板节点和内部连线实时绘制等比例缩略图，并可拖拽或双击复用。命名弹窗与卡片中的缩略图分别约束在自己的预览边框内居中显示；卡片空间变窄时 Canvas 宽高联动缩小，保存前后的形状比例保持一致，不会拉伸或偏移到页面左上角。自定义组件缩略图中的文本节点使用实际 `node.text` 显示中文正文，并启用仅用于模板缩略图的小尺寸可读文字策略；该策略不改变结构列表和属性面板顶部固定显示的“文本”，也不作用于普通画布鹰眼。组合缩放通过持久化 `visualScaleX/visualScaleY` 分轴累计横向和纵向倍率，使文字、表格、表单和设备内部结构随组合一起缩放或拉伸，不再只改变外框；成员自身角度保持不变。模板数据随图纸保存，组合、模板实例、撤销重做和保存恢复统一按节点集合约束位置，不改变成员相对布局
- 铅笔可从空白画布、任意已有组件内部或边缘、锁定组件及已有铅笔线稿上方直接起笔；落笔完成后生成置顶的普通 `pencil` 组件，可连续绘制、框选、多选、移动、八方向缩放、旋转、锁定、调整图层、复制、组合及添加到“我的”；另支持起止端口和边缘/中心锚点的节点连线
- `Alt + 左键`或鼠标中键拖动画布平移、画布位置固定、`20%–1000%` 鼠标原位锚定缩放（靠近真实边界时只夹取越界轴）、视图重置、网格吸附，以及包含组件真实缩略图与当前窗口框的鹰眼导航；滚轮和按钮每档按 `1.1` 倍连续缩放，高分辨率触控板同一帧内的全部滚轮档位直接生效，不额外限制单帧幅度
- 大图纸使用均匀网格空间索引查询编辑视口、原始像素预览和框选范围；超过 1,500 个节点时把视口缓冲从 `240px` 收紧为 `96px`，大范围及低倍率查询只遍历实际占用的网格桶。移动、缩放、旋转只更新受影响节点的索引，活动节点不会在拖出视口时卸载。节点 ID 索引使用持久 `Map`，普通增删按批次登记 Vue 代理，只有整体换图才重建。连续滚轮不逐帧发布全局 `zoom`；当目标视口超出现有覆盖时，先通过空间索引把当前与目标范围的并集增量挂载，再应用舞台合成变换，停顿 `96ms` 后一次提交并收敛最终视口。表格、表单、铅笔及线段的复杂渲染键按节点缓存，避免每次缩放重复序列化。连续几何操作只保存相关节点几何差异；新增、复制、粘贴、模板实例化、完成铅笔/线段、建立连线和删除只保存受影响实体。鹰眼复用主页面索引并以浅版本刷新，超过 1000 个节点时优先在浏览器空闲阶段绘制；右侧“结构”面板采用窗口化列表，画布层级直接读取实体自身 `layer`，数千图层时不会为普通缩放额外排序全部层级
- Worker 返回已经校验和归一化的图纸后，主线程由 `projectRuntimePreparer` 按默认 `4ms` 时间片建立节点、线稿、时间、运行绑定、空间、邻接和图层等完整私有运行索引，全部完成后再一次安装实体集合与索引，不把半成品暴露给编辑器。大图加载、退出预览或从持久 LOD 回到普通倍率时，若当前首屏节点超过 `128` 个，先保留 Canvas 连续画面，再按每帧最多 `8` 个节点、`64` 挂载成本渐进交给完整 DOM，避免同一帧集中创建复杂组件。普通倍率下当前视口连线超过 `1,024` 条时启用 edge-only Canvas：Canvas 只承载超密连线，节点和铅笔/线段仍由完整 DOM 渲染并保持编辑能力；活动 SVG 连线、指针帧邻接边和几何 payload 均限制为最多 `128` 条。高出度节点超过该门槛时不在拖动帧枚举全部连线，松手后再由独立的索引压实任务以 `2ms` 分片构建私有空间/邻接索引并原子安装
- 首次静态 Canvas 帧的边数组长度或空间索引 `entries` 达到 `2,048` 时，边栅格化转交 OffscreenCanvas Worker。全图边数组与原始尺寸/全屏 edge-only 的空间查询 cursor 使用同一通道：主线程在现有 `2–6ms` 调度预算内计算端点，cursor 每个查询子片最多处理 `256` 个索引条目，只要本时间片仍有预算就继续收集，尽量组成最多 `512` 条的 transferable typed arrays 批次。Worker 复用同一逐边绘制函数，保持连线顺序、独立 `stroke()`、虚线和首尾标记；每条边绘制后恢复调用方原有 `lineCap`，避免共享 context 的后续图元继承圆头状态，完成后只回传一个 ImageBitmap。每条 cursor 命中边会先加入 `task.edges` 再推进剩余 cursor；Worker 创建、发送、协议、合成失败或 start/batch/finish 任一阶段 `8s` 无响应时，主线程从头重放已收集的 `task.edges`，随后继续未消费 cursor，保证不漏边、不重复。edge-only 完整帧提交后不保留节点运行值所需的静态/合成双离屏面
- 属性、通信、布局和图层结构面板；通信页按“组件参数 → 数据源 → JSON 字段/JSONPath → 类型预览 → 手动确认”建立动态绑定，相同源和路径只解析一次，旧 `pointId` 图纸保持兼容；文本组件在结构列表和属性面板顶部统一显示稳定名称“文本”，不使用正文作为组件名称，正文仅在“文字编辑”的内容项中展示和修改
- 文本组件的右侧内容输入和画布双击内联编辑均支持在输入框保持焦点时直接切换中英文；Shift、Ctrl+Space、Process 和中文候选确认不会被编辑器快捷键提前拦截，右侧输入由 Vue 原生组合态保护后同步到画布
- 文本组件会原样显示多个连续空格，可用空格在两段文字之间形成可见长间隔；“文字排布”提供横向和竖向两种模式，竖排字符保持正向并从上到下排列。编辑画布、普通/全屏预览、鹰眼和“我的”缩略图使用同一排布字段，旧图纸缺少该字段时继续按横向显示
- 低倍率高清 Canvas 为文字提高屏幕可读字号前，会先按节点原字号计算并复用横排换行或竖排列基线，再按原布局剩余空间限制字号；组合放大后的文字不会因低倍率可读字号重新换行而相互重叠。正文 `String.length > 512` 时，完整帧、dense 重放和 sparse 局部重画都把字素拆分、换行和测量放入可取消的分片布局，当前实体完成前不推进游标，也不把半段文字提交到可见画布
- 表单样式在前、类型专属数据在后；表格默认使用浅灰业务表格样式，支持标题/表头/内容独立字体与对齐、虚实内框、表头高度、统一或逐行高度、逐列精确像素宽度、长文本自适应或缩略查看、指定单元格合并与拆分、列名摘要、完整数据面板、画布双击编辑和横纵滚动条独立显隐
- 时间组件可独立设置 `8–96px` 文字字号以及常规、中粗、粗体三档粗细，编辑画布、普通/全屏预览和鹰眼统一读取同一设置
- 编辑画布双击表单组件可直接操作，复选框、单选框、开关和选择器均支持反复切换；按钮在计数动作中可控制纯数字次数显隐，切换动作支持独立设置点击前后颜色且不显示次数，消息动作弹出自定义确认内容。按钮进入编辑态交互后仍可连续点击，也可直接从按钮主体按住并移动超过 `4px` 拖动组件，无需先把鼠标移出组件
- 普通预览可在原始像素滚动与自适应完整显示之间切换；全屏预览使用浏览器原生 Fullscreen API 隐藏导航界面和普通预览标题栏，并严格按图纸实际像素从左上角显示，超出屏幕时滚动查看，同时支持表单真实交互与动效运行。原始尺寸或全屏当前带缓冲视口超过 `1,024` 条连线时，只把连线移入高 DPI、按视口更新的 edge-only Canvas；节点、线稿、表单、媒体和动画继续使用完整 DOM。自适应和 edge-only Canvas 只有在位图预算能够达到请求像素比、且完整帧报告的实际像素比也达到请求值时才交接，否则分别保留清晰 DOM 或恢复完整 SVG 连线，不展示被放大的低密度位图。edge-only 的计划键包含请求 DPR；完整帧写入可见 backing 前，`frameCommitGuard` 先校验路径仍活动、计划、范围和 X/Y 中较小的实际 DPR，显示时再校验 committed 计划/范围/DPR 及其对当前视口的覆盖。迟到的旧计划或旧范围帧直接丢弃且不清除当前 ready；当前匹配请求若实际 DPR 不足则停用本次 edge-only 并明确恢复完整 SVG。设备 DPR 提高或计划变化后，旧 Canvas 立即失去接管资格，完整 SVG 连线会一直保留到新的清晰帧提交
- “图纸”分类支持新建、选择编辑、删除，以及按图纸标题或实际文件名搜索多张图纸；搜索栏在“图纸”页显示“搜索图纸”，保存及 `Ctrl+S` 始终绑定当前正在编辑的图纸。未保存图纸的规范化文件名若已存在于图纸库，卡片会提前标记“未保存 · 同名冲突”；两个未保存会话指向同一规范化目标时标记“未保存 · 同名目标”。卡片显示完整的 `图纸库/<名称>.json` 目标，tooltip 分别说明库内冲突或另一未保存会话冲突及处理方式
- 撤销重做、项目 `图纸库/` 打开/保存/删除、图纸会话删除，以及其他位置打开/另存为；从“打开”选择文件时始终重新读取磁盘 JSON，并完整恢复画布组件、“我的”模板和图纸设置，不使用同名旧内存会话替代文件内容
- 按工作空间隔离的浏览器恢复缓存、图纸修订冲突检查和跨图纸会话清理；完整多图纸会话写入 IndexedDB，内存 LRU 只有在该工作空间最新快照成功落盘后才允许淘汰，保存失败或仍有更新的脏会话继续留在内存；切换工作空间时先锁定界面、收束当前交互，并等待已经开始的组件包处理和图片/视频读取完成，再持久化旧会话并恢复目标工作空间
- 工作空间级数据源和旧点位兼容目录默认写入独立 IndexedDB：连接元数据与点位分片由 manifest 关联，点位每块最多 `256` 条，全部新块成功后才发布新 manifest，失败继续保留上一份完整快照；支持 Web Locks 时，各标签页按工作空间独占并在锁内刷新 durable manifest，避免复用已被其他页面回收的旧分片。旧 localStorage v1/v2 数据只在迁移提交成功后清理。首次激活十万级点位目录时，按默认 `4ms`、每片最多 `4096` 次操作建立私有来源/点位索引和状态统计，完成后一次安装，重复 ID、取消或失败不会暴露半成品

“我的”分类固定使用桌面两列大卡片，保留 `64 × 54` 等比例真实缩略图、名称、组件数量和删除入口；卡片支持拖拽、双击以及键盘 Enter/Space 添加，窄屏时切换为单列，优先保证组合预览清晰可辨。

常用操作：空白区域拖动框选，`Ctrl/Cmd/Shift + 左键`增减多选，`Alt + 左键`或鼠标中键平移；快捷键包括 `Ctrl+S` 保存、`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+D` 复制、`Ctrl/Cmd+G` 组合、`Ctrl/Cmd+Shift+G` 取消组合、`Delete` 删除、`Esc` 取消框选、退出全屏、关闭预览或退出当前工具。

项目启动时会沿用现有方式创建并访问项目根目录的 `图纸库/`（不存在时创建）。“图纸”分类管理当前打开或新建的前端编辑会话，可新增、选择编辑和移除；左侧卡片的移除不会删除磁盘文件。顶部“打开”每次都重新读取并校验选中的磁盘 JSON；其图纸库列表的垃圾桶按钮经二次确认后会永久删除项目图纸文件。若文件已打开，画布内容保留为未保存图纸。删除请求失败后不会根据过滤后的列表猜测文件已不存在：仅当 DELETE 明确返回 `404`，或轻量 `HEAD /api/drawings/:name` 探针确认普通文件不存在时，才解除会话文件身份；探针故障时继续保留绑定。顶部“保存”只写入当前激活图纸。新图纸首次保存使用 `If-None-Match: *`：图纸库已有同名文件时返回 `412` 并明确提示名称冲突，原文件不会被覆盖；只有已绑定图纸库文件的会话才使用精确 `If-Match` 更新，旧 ETag 返回 `412` 并提示版本冲突。也可以从其他位置打开或另存到用户选择的位置，但图纸库删除不会操作这些文件。

本地图纸库 API 的单图读写上限默认是 `256 MiB`（`268435456` 字节），可在启动前用正整数环境变量 `TC2D_MAX_DRAWING_BYTES` 覆盖。服务在磁盘 stat 后、`readFile` 前执行门禁：超限文件不会出现在列表中，直接打开返回 `413`，保存冲突校验和删除读取也使用同一上限；检查早于 metadata 缓存命中。`PUT` 的 `Content-Length` 或流式累计字节数超限同样返回 `413`，压缩请求体被拒绝。图纸列表、读取、保存、删除和 HEAD 存在性探针均不受通用 `15s` 固定超时提前中断；浏览器“其他位置”的文件句柄不经过该本地 API，但仍受浏览器、设备和相同结构校验约束。

完整多图纸工作空间会话由 IndexedDB 保存，包括各图纸内容、历史和文件身份。大会话正文按默认 `4ms` 时间片增量编码为 `64KiB` Blob chunks，发现待处理输入立即让步；IndexedDB 的单 key 原子 `put` 只接收小型 envelope 与 Blob 引用，不再同步克隆整份对象图。保存版本在编码期间和写入前持续校验，过期快照不会落盘；旧 object 快照仍可读取，自定义文件句柄不可克隆时保留无句柄降级。`localStorage` 只保留当前活动图纸的小型兼容恢复副本；它复用同一增量编码器，以默认 `4ms` 时间片和最长 `4KiB` 字符串片段推进，累计超过约 4 百万字符时立即停止并删除兼容 key，不再先同步 `JSON.stringify` 整张大图。跨标签存储事件和保存冲突检查只让 `projectJson.worker.js` 返回 `projectId/revision/updatedAt` 头部，不把完整图纸克隆回主线程。图纸库、其他位置和 localStorage 兼容恢复中的 JSON 字符串仍由 Worker 完成 JSON 解析、结构/容量校验、旧版本迁移和模型归一化，再把 `nodes/edges/drawings/customComponents` 以每块最多 `128` 项、目标约 `1MiB` 的协议分块回传主线程；Worker 不可用、创建/发送失败或运行异常时回退同一操作的主线程实现。主线程随后由 `projectRuntimePreparer` 按默认 `4ms` 时间片建立完整私有运行索引并一次安装。前端导入与本地服务共用结构容量契约：画布节点与旧临时线稿合计 10,000、连线 20,000、旧临时线稿 5,000；顶层和“我的”模板中的铅笔/线段点与旧线稿点合计 250,000，单个 `polyline` 最多 10,000 点；“我的”最多 200 个模板，全部模板合计 2,000 个节点和 4,000 条内部连线。单个本地视频的 20MB 上传限制仍只约束媒体入口。

当前共使用三个专用 Worker：`projectJson.worker.js` 负责大图解析、校验、迁移、归一化和分块回传，`largeSelectionTransform.worker.js` 负责大选区最终几何，`edgeRaster.worker.js` 负责超密静态边的 OffscreenCanvas 栅格化；三者全部保留等价主线程分片降级，不把功能正确性绑定到 Worker 能力。

图纸列表按文件 stat 签名缓存已校验的 metadata/ETag；直接读取可写入当前缓存，保存会在写后重读核对 ETag 并在验证前后失效缓存，删除也主动失效。内容未变化且确定为 `422` 的无效文件使用负缓存，文件签名变化后重新校验，临时 I/O 或读取竞态错误不会被缓存。自适应预览只允许受 `24/16/128` 门禁约束的“Canvas 静态前缀 + DOM 完整尾段”安全混合层，无法证明层级、预算或请求像素比时回退完整 DOM。正常等待 Canvas 时，`ProgressivePreviewNodes` 只挂载当前带缓冲视口 DOM；仅在 Canvas 计划不适用或渲染失败时才渐进请求完整图纸 DOM。失败当下先显示原尺寸 DOM 保证非空和清晰，完整 DOM 挂载完成后再原子切换为 `dom-fit`。完整回退中的节点、连线和线稿都按帧挂载：节点由 `ProgressivePreviewNodes` 处理，连线和线稿由 `ProgressivePreviewGeometry` 分别以首批 `64/8` 个开始渐进提交；几何层保留稳定不可变批次，按 `nextTick` 后实际提交耗时自适应，倍率最多为 `4`。只有节点层与几何层都报告当前世代和当前数量完整 ready，且 `showPreview`、`previewDomMounted` 仍有效、交接目标仍为 `dom`，`finishPreviewDomHandoff()` 才允许进入 `dom-fit`；关闭预览会先推进 `previewDomGeneration`，使迟到完成事件失效。新世代会立即剔除不再属于目标集合的陈旧 DOM，并用当前同 ID 节点引用替换旧引用；缺失节点在同一挂载数组上原地增长，节点批次按 `nextTick` 后实际提交耗时在 `1–16` 倍间自适应。预览节点的 `v-memo` 显式包含 `node` 引用，保证对象被替换但 ID 不变时仍刷新。Canvas 复用池会隔离无法取得 2D context、创建期绘制异常或恢复失败的 surface；节点、图片、线稿、线段、设备和边 marker 的嵌套 `save()/restore()` 均在异常路径配对恢复，局部几何失败后转入既有 fallback/完整帧恢复，不把污染后的 transform、alpha、dash 或 clip 带入下一实体。图片成功加载事件按动画帧合并，失败不触发整图重绘；隐藏的 fit surface 暂停完整帧、运行值、时间和图片调度，重新激活时只追赶一次最新状态。

生产构建注册前置 `cleanBuildOutputPlugin()`，在 `configResolved` 后只解析一次输出目录；清理前同时校验其词法路径和最近现存祖先的 `realpath` 都位于项目根目录内且不等于项目根目录，再递归删除本轮 `dist/`。同时保留 Vite 的 `build.emptyOutDir: true`，避免部署混入上一轮哈希资源，也避免错误配置越界清理。

## 后台接入预留

当前版本仍按纯前端开发方式运行，Vite 本地插件提供同源 `/api/drawings` 和 `/api/time`，没有账号、数据库或真实实时通信后台。画布业务已不直接调用 `fetch` 或创建通信连接，统一经过 `src/services/`：

- `httpClient.js`：API 基地址、超时、统一错误、JSON 解析和未来鉴权头入口。
- `drawingRepository.js`：图纸列表、读取、保存、删除、HEAD 存在性探针及 ETag 条件请求。
- `timeService.js`：服务器时间与明确的本机时间回退。
- `pointCatalogGateway.js`：工作空间级数据源连接和结构化快照契约；当前为纯前端示例适配器。
- `sourceBindingRuntime.js`：按 `sourceId + JSONPath` 去重派生运行值，并对高频快照执行 latest-wins 和分片。
- `runtimeGateway.js`：把任意消息归一化为 `{ key, value }[]`，当前装配本地模拟数据。
- `operationGateway.js`：画布历史检查点的操作事件入口，当前为空实现，不上传或保存用户操作。
- `backend.js`：当前适配器装配点，未来接后台时优先在这里替换实现。

后台与前端同源时无需配置。分离部署时可在构建前设置 `VITE_API_BASE_URL`，例如 `$env:VITE_API_BASE_URL='https://api.example.test'`；图纸与时间后台继续提供 `/api/drawings`、`/api/drawings/:name` 和 `/api/time` 契约。接入真实数据源时，生产适配器还需实现连接生命周期和 `{ sourceId, revision, quality, data }` 结构化快照契约，具体路由由 `pointCatalogGateway` 的后台实现确定，组件和画布不直接请求 MQTT、数据库、Socket 或 WebSocket 服务。前端传入的 `workspaceId/projectId/revision` 只是请求上下文，当前本地适配器不会把它拼入 URL；生产服务必须从已认证会话取得用户和租户身份，不能信任客户端提交的归属字段。

浏览器文件选择器的“打开其他位置/另存为”保持独立能力，不走图纸后台仓储。图纸快照、低频操作审计和高频实时数据是三条不同通道，后续不能把鼠标移动或设备高频值逐条写入完整图纸快照。
