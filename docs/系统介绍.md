# 苔岑2D绘图系统介绍

## 1. 系统概述

苔岑2D绘图是一个浏览器端可视化图形编辑器，用于绘制流程图、工业监控图、网络拓扑、设备面板和数据展示画面。系统提供组件库、可滚动画布、节点变换、图层管理、连线、自由绘制、实时数据绑定和动态预览。

主要能力：

- 基础图形、独立线段、表单、流程、工业设备、图表、网络、内置动效与自定义动效组件。
- 拖放添加、自由移动、缩放、旋转、锁定、图层排序以及多选组合/取消组合；组合可作为整体继续移动、缩放和旋转。
- 将单个组件或组合保存到“我的”，并通过拖拽或双击重复使用。
- 铅笔线稿完成后生成普通组件；线段工具按多个落点逐段即时连接并在完成后生成一个普通组件。两者均可参与框选、多选、组合和全部节点变换；系统另提供节点连线、网格、缩放和鹰眼地图。
- 右键菜单、剪切复制粘贴、撤销重做和快捷键。
- 项目 `图纸库/` 打开/保存/删除、其他位置打开/另存为和可交互预览。
- 按工作空间隔离的浏览器恢复缓存、项目修订检查和跨图纸会话清理。
- WebSocket、MQTT、HTTP 数据接入界面及高频数据批处理层。
- 大图纸编辑和预览视口虚拟化、增量文档索引，以及鹰眼离屏分片渲染。

## 2. 所用技术

| 技术 | 当前版本 | 用途 |
| --- | --- | --- |
| Vue | 3.5.40 | 响应式状态、组件和界面渲染 |
| Vite | 8.1.5 | 开发服务器和生产构建 |
| JavaScript | ES2022+ | 编辑器逻辑和数据模型 |
| SVG | 浏览器原生 | 连线、箭头和自由绘制路径 |
| HTML/CSS | 浏览器原生 | 节点、面板、菜单及动画 |
| Lucide Vue | 1.0.0 | 工具栏和组件库图标 |
| Node.js 文件服务 | 本地运行时 | 创建项目 `图纸库/` 目录并提供图纸文件列表、读取、保存、删除和 HEAD 存在性探针 |
| 前端服务适配层 | 原生 ES Module | 统一图纸仓储、HTTP、服务器时间、运行时数据和操作事件边界 |
| IndexedDB | 浏览器原生 | 按工作空间持久化完整多图纸会话、文件身份和历史 |
| localStorage | 浏览器原生 | 当前活动图纸的小型兼容恢复副本及最近工作空间标识 |
| Web Worker / OffscreenCanvas | 浏览器原生 | 在后台线程解析、校验、迁移和归一化大图纸并分块回传；2,048 条以上静态边可在专用 Worker 栅格化。两条路径在不可用或异常时均回退主线程实现 |
| requestAnimationFrame / requestIdleCallback / MessageChannel | 浏览器原生 | 指针节流、数据合并、后台空闲分片，以及活动预览和编辑 detail 的 task 分片调度 |

编辑和预览逻辑在浏览器中运行；自动创建项目 `图纸库/` 目录及默认打开、保存、删除需要本地文件服务。生产环境若只部署静态构建产物，必须提供等价的图纸 API；需要账号级多用户隔离时，还必须增加认证、租户权限和服务端修订控制，客户端工作空间名称不能替代服务端权限校验。

## 3. 系统环境

### 已验证环境

- 操作系统：Windows，PowerShell 终端。
- Node.js：v24.8.0。
- npm：10.9.0。
- 开发地址：`http://localhost:4173/`。
- 字符编码：UTF-8。

### 推荐环境

- Windows 10/11 x64 或主流 Linux x64。
- Node.js 20 LTS 及以上版本。
- npm 10 及以上版本。
- Chrome、Edge 或其他支持 ES2022、CSS clip-path 和 ResizeObserver 的现代浏览器。
- 开发内存建议 4GB 以上；大型工业图纸建议 8GB 以上。

### 端口和存储

- Vite 开发端口由命令指定，当前预览服务为 `4175`。
- 本地文件服务启动时检查项目根目录的 `图纸库/`，目录不存在时自动创建；该目录是顶部“打开”和“保存”的默认文件位置。
- “打开其他位置”和“另存为”使用用户选择的本机位置；图纸内部仍采用版本化 JSON 数据结构，但界面不再把 JSON 导入、导出作为独立功能。
- 最近工作空间标识保存在 `tc2d-active-workspace`；完整多图纸会话按工作空间写入 IndexedDB。`tc2d-project:<encodedWorkspaceId>` 只保留当前活动图纸的小型 localStorage 兼容恢复副本，旧 `tc2d-project` 可迁移到默认工作空间；浏览器恢复存储都不能替代正式图纸文件。

当前图纸格式版本为 `20`。加载旧图纸时，原来借用 `borderWidth` 表示粗细的直线会迁移为真实高度，原描边色会初始化为线条本体填充色，并调整 Y 坐标保持视觉中心；画布节点和“我的”模板中的直线使用同一迁移规则。

| `src/workers/edgeRaster.worker.js` | 使用 OffscreenCanvas 按原顺序逐边绘制达到 2,048 门槛的数组或空间查询静态连线，接收最多 512 条一批的 transferable typed arrays；共享绘制函数在每条边后恢复调用方原 `lineCap`，完成后转移单个 ImageBitmap。取消、8 秒失联或失败时由主线程从已收集边继续剩余 cursor 的无损分片路径接管。 |
| `src/workers/projectJson.worker.js` | 在独立线程解析图纸 JSON，执行结构/容量校验、旧版本迁移和模型归一化，再按协议分块回传准备结果；错误返回结构化失败，Worker 不可用或崩溃时由主线程执行同一操作。 |

核心编辑会话、命令和页面编排位于 `src/App.vue`。新增组件优先修改目录配置；新增保存字段或旧版本迁移优先修改编辑器模型；接入真实后台通过服务适配层完成，不在画布事件中直接发请求。

代码中的中文注释重点解释旧数据兼容、组合几何、性能裁剪、撤销内存限制、多窗口并发和生命周期清理。结构与扩展细节见 `docs/CODE_GUIDE.md`。

图纸属性的“画布尺寸”提供“使用当前屏幕尺寸”按钮。点击时实时读取当前显示器的 `screen.width × screen.height` CSS 像素并写入画布宽高，无法读取屏幕信息时回退到当前窗口视口；非固定预设尺寸自动显示为“自定义”。该尺寸与浏览器全屏预览使用的坐标单位一致，便于按目标屏幕进行一比一布局。

通用文字粗细统一提供“常规、中粗、粗体”三档，对应字重 `400 / 600 / 700`。旧图纸中的固定字重或粗细倍数会在加载时自动映射到最接近的档位；中粗和粗体使用不同强度的轻量同色描边辅助显示，确保中文字体缺少完整原生字重时三档仍有可见差异。组件边框保留 `0–100` 圆角设置；直线不显示圆角，其宽度和高度分别作为实际长度和粗细，不再依赖不可见容器。新建直线默认为 `150 × 8px`，使用绿色本体和 `2px` 深灰轮廓；属性面板提供线条颜色、不透明度、实线/虚线/点线、线段长度和间隔，以及轮廓显隐、颜色和宽度。虚线和点线直接分隔线条主体，不再只改变外框。

“直线”仍是“基本形状”中的单段图形；“线段”是独立分类中的多点连续绘制组件，两者不互相替代。线段的“线条样式”沿用直线的控件顺序、术语和视觉风格；其后的“线段属性”提供线宽、`1–100px` 箭头大小、起点箭头、终点箭头、端点样式和连接样式。箭头大小由两端共用且不再随线宽自动放大。

表单分类和图表组件中的进度条均可独立设置 `2–80px` 粗细、占可用区域 `10%–100%` 的长度，以及左右端分别使用矩形或圆形。范围波动可手动开启或关闭；开启后按设定周期在 `0–1` 下限与上限之间连续往返，填充长度和百分比文字使用同一实时值同步更新，关闭后恢复静态进度值或通信数据。表单进度条开启波动时暂停手动拖动，关闭后恢复交互。

### 顶部工具栏

顶部工具栏集中提供打开、保存、选择、铅笔、鹰眼地图、连线、撤销、重做、锁定、组合/取消组合、置顶、网格和预览命令，不再显示重复的“文件”按钮。画图工具与工作空间功能分别由 `EDITOR_TOOLS`、`WORKSPACE_TOOLS` 维护；“数据源”属于独立工作空间功能，左右使用竖线与画图工具和编辑命令分隔，打开管理页但不切换画布工具模式。组合按钮常驻显示，少于两个组件时禁用，形成有效多选后立即可用，已组合时切换为“取消组合”。“打开”优先列出项目 `图纸库/` 目录中的文件，每行的垃圾桶可在二次确认后删除该图纸库文件，也可转到其他位置；“保存”和 `Ctrl+S` 只写入左侧已激活、正在编辑的图纸，已有文件保存回原文件，新图纸写入项目 `图纸库/`，也可另存到用户选择的位置。当前激活工具使用绿色背景标识，不可用的命令会自动禁用。

### 左侧图纸与组件库

“图纸”页搜索栏显示“搜索图纸”，输入关键词后按当前会话的图纸标题或实际文件名实时筛选，英文匹配不区分大小写。无匹配结果时显示空状态，但保存、打开和新建入口仍可使用；切换左侧分类会清空上一分类的搜索词。

“图纸”页按卡片列出当前工作空间中已打开或新建的图纸会话。点击“新建图纸”会新增一张独立空白图纸，不覆盖其他图纸；点击卡片会激活该图纸用于编辑和保存，同时清除对象选择并在右侧“属性”面板打开对应图纸和画布设置。每张卡片提供独立删除入口；该操作只从前端图纸分类移除会话，已保存到项目 `图纸库/` 或其他位置的文件不会被删除。删除当前图纸后自动切换到相邻图纸，删除最后一张时自动建立空白图纸。“我的”页列出当前图纸保存的自定义组件模板，并在列表下方显示当前工作空间与切换入口。用户可把单个组件、多选组件或现有组合通过右键“添加为我的”保存为模板；保存前会弹出名称编辑和等比例缩略预览，只有确认后才写入图纸和撤销历史。命名输入框在弹窗 DOM 挂载后立即聚焦，只拦截自身处理的普通 Enter 或 Escape；Shift、Ctrl+Space、Process 等输入法切换和组合按键保持浏览器原生处理，因此从英文状态切换中文无需先离开当前页面，中文候选确认的 Enter 也不会提前提交模板。工作空间名称和画布内联文字也采用相同的中文组合输入保护，`Ctrl+S` 等其他快捷键仍可继续执行。命名弹窗左侧预览和“我的”卡片缩略图均固定在各自边框内部居中；卡片空间不足时宽高使用同一比例联动缩小，因此保存后的卡片与保存前弹窗保持相同形状比例，不会拉伸、占用或偏移到页面其他位置。模板保留完整节点属性和所选节点之间的内部连线，“我的”卡片直接从这些数据实时绘制可辨认的真实轮廓，不额外保存重复位图。文本节点在命名预览和保存后的卡片中读取实际 `node.text` 绘制中文正文，并使用只为自定义组件缩略图启用的小尺寸可读文字策略；结构列表和属性面板顶部仍固定显示类型名称“文本”，普通画布鹰眼也继续使用原有概览绘制规则。模板可像普通组件一样拖到画布或双击添加，也可从列表删除。模板实例化时以整套节点为单位约束位置，组合成员不会因逐个校正而错位。模板数据随当前图纸 JSON 保存，不同图纸和工作空间互不混用；切换工作空间时仍会清空剪贴板和运行时状态。“组件”页按基本形状、线段、表单、流程图、工业设备、图表、网络与云、动效组件、自定义动效分类。“基本形状”保留直线和视频播放等组件；独立“线段”分类只提供多点连续绘制的线段组件；表单分类提供表格、复选框、单选框、开关、进度条、按钮、输入框、选择器和时间 9 种组件，并使用与名称一致的图标。普通组件可以拖到画布或双击添加；线段卡片只能拖到画布启动，松开位置作为第一个节点，组件库单击或双击均不启动线段。底部总开关根据当前状态展开或收起全部图形库。搜索框按组件名称实时过滤，收起全部时会退出强制展开的搜索状态。

“我的”分类最终保留原来的两列大卡片布局，每张卡片使用 `118px` 稳定高度和 `64 × 54` 等比例真实缩略图，完整显示名称、组件数量及删除按钮；卡片仍支持拖拽、双击、Enter 和 Space 添加，窄屏时改为单列。该布局优先保证包含多个图形的组合缩略图清晰可辨，不再压缩为与普通组件图标相同的三列小格。

### 中央编辑画布

线段从独立分类拖入画布后，拖拽落点成为第一个节点并显示为比其他落点更大的可拖拽锚点。继续落点前或绘制过程中都可拖动该锚点精调起点；拖动只修改第一个节点，不会新增节点。开启网格吸附时锚点遵循当前网格，拖动时按住 `Alt` 可临时取消吸附且不会触发画布平移。完成或取消线段、`Backspace` 撤回到零点后，锚点与草稿一起消失。

画布宽高支持常用预设和 `320–20000px` 自定义尺寸，灰色工作区与实际画布页面边界明确分离。新建和首次打开的软件使用空白图纸，不再预置示例组件。选择工具下从空白区域向任意方向拖动会显示蓝色选择框，松开后选中与框选区域相交的全部组件；按住 `Ctrl`（macOS 为 `Cmd`）或 `Shift` 再框选会在当前结果上追加。`Alt + 左键`或鼠标中键拖动用于平移画布，滚轮以鼠标位置为中心缩放，另有视图固定、重置、线条或点阵网格和自由像素摆放。固定视图后，平移、滚轮、滚动条和鹰眼均不能改变当前缩放与定位，但组件仍可编辑。鹰眼按当前画布宽高生成 `240 × 150px` 缩略图，不再只画节点边框；基础图形显示真实几何轮廓，管道、风机、表格、表单、图表和设备显示类型化内部特征，图片显示实际图像，铅笔和线段显示实际路径，连线也同步绘制。蓝色框表示当前窗口，点击鹰眼任意位置可把主画布定位到对应区域。节点可以移动、八方向缩放、任意角度旋转和连线；直线的横向手柄修改实际长度，上下及角部手柄修改实际粗细，不再改变不可见的容器高度。线段必须从组件库拖到画布启动，松开位置作为第一个节点；之后每次单击都会把上一个点与新点立即连接成直线。任意多个相邻点共同显示为一条连续路径，画布双击或 `Enter` 后才作为一个 `polyline` 节点进入统一组件链路，完成后立即切回选择工具。`Esc` 或右键取消当前草稿并切回选择；`Backspace` 撤回末点，删除到零点时同样切回选择。每条新线段都必须重新从组件库拖拽。普通组件缩到 `1 × 1px`、直线缩到 `1 × 0.1px` 后，节点中心仍有按画布比例反向补偿的透明拖动层，屏幕命中尺寸至少为 `24 × 24px`；最低 `20%` 缩放时也能从视觉本体之外选中并拖动，极小状态的八个缩放手柄会向外分离。普通组件、直线、旋转节点和组合无论是否占满或超过画布，均可向上、下、左、右部分移出画布；每条轴按旋转后的视觉跨度保留操作区，跨度达到 `48px` 时保留 `24px`，不足 `48px` 时保留一半视觉跨度，同时不超过该轴画布尺寸的一半。直线竖直移动与其他组件使用同一规则。未组合多选会同时保证每个成员仍有可操作区域；正式组合固定以组内一个真实成员作为稳定锚点并对全组应用相同位移，避免稀疏组合只有空包围区域跨过画布、实际成员却全部不可见。画布尺寸变化、撤销重做、模板实例化、保存和重新打开均以完整节点集合归一化，避免成员相对位置被拆散或越界位置重开后跳回。缩放手柄位于组件真实边界之外，不遮挡多个组件组合时的顶点与边界交点。按住 `Ctrl/Cmd` 或 `Shift` 并左键单击可逐个增加或移除多选节点，普通单击未选节点恢复单选；多选后直接拖动任一已选成员会保留当前选择并整体移动。框选或单击命中组合成员时会自动扩展到完整组合。选中至少两个节点后，画布显示统一组合选框，顶部工具栏、右侧属性栏和右键菜单同时提供“组合为组件”；组合完成后选框变为绿色，八个边角手柄按整体边界同步缩放全部成员，顶部手柄围绕整体中心旋转，拖动任一成员会同步移动整组。组合使用持久化 `groupId`，单击任一成员会选中整组；整体 X、Y、宽、高、锁定、删除、剪切、复制和图层调整均以当前多选或组合为范围。选择“取消组合”后只清除组合关系，各成员的当前位置、尺寸、旋转角度、图层和连线保持不变。连线以第一次选择的组件为起点、第二次选择的组件为目标，起点和终点可分别设置为无端口、箭头、圆点或方块，连接点可使用组件边缘或中心。铅笔线稿在绘制期间使用临时路径，落笔结束立即转换为普通 `pencil` 节点；铅笔和已完成线段此后均与矩形等组件使用同一选择和变换链路，支持框选、`Ctrl/Cmd/Shift` 多选、组合、整体移动/缩放/旋转、锁定、图层、复制、删除及添加到“我的”，同时保留精确位置尺寸和线条样式编辑。右键菜单还提供添加为我的、图层、锁定、删除、撤销、剪切、复制和粘贴。

鹰眼始终使用 `contain` 等比缩放，横纵方向共用同一个比例，不会为了铺满固定窗口而把宽画布压窄或把高画布拉长；当画布与鹰眼宽高比不同时，缩略内容居中并在上下或左右保留空白。鹰眼容器、整张画布边界和当前窗口位置具有明确层级：`240 × 150px` 容器使用中性灰背景；缩略 Canvas 只在真实画布投影范围内填充画布背景并裁切组件，留白仍显示容器灰色；低对比深灰 `2px` 边框圈出整张画布。当前窗口恢复为原来的 `#168eea`、`2px` 蓝框，并且只在深灰整图边框内部移动。组件、临时线稿和连线按主画布图层关系绘制，连线的边缘/中心锚点及起止箭头、圆点、方块也与主画布使用同一套几何规则。缩略内容、整图边框、当前窗口框和点击定位共享同一个比例与留白偏移，因此点击容器留白或画布边缘时也会夹取到真实画布范围。超大图纸中的当前窗口自然投影不足 `12px` 时，鹰眼会围绕真实投影中心扩展到至少 `12 × 12px`，不会把标记错误固定在一侧；只有靠近整张画布边界时才做边界夹取。鹰眼使用单个 Canvas 按动画帧合并更新，而不是为每个组件复制一套 Vue DOM，避免大型图纸因打开鹰眼而显著增加节点数量和布局开销。

上述“以鼠标位置为中心缩放”指首次滚轮同时保存鼠标在画布内容区的局部坐标和对应画布逻辑坐标；倍率变化后，该逻辑点仍保持在鼠标原来的屏幕位置，不再主动移到编辑视口中央。连续滚轮基于尚未提交的投影倍率和滚动位置继续计算，并在鼠标移动不超过 `8px` 时复用首次锚点，避免触控板连续事件产生漂移；靠近真实画布边界时只夹取越界的 X 或 Y 轴，另一轴继续保持锚定。缩放范围为 `20%–1000%`，滚轮和按钮每档按 `1.1` 倍变化，同一帧的高分辨率触控板档位完整累计，不做额外幅度限流；工具栏按钮没有鼠标事件时以当前视口中心作为锚点。

组合统一选框保留八个缩放手柄，但按方向使用不同规则：四个角手柄保持组合原始宽高比，左右边中手柄只改变整体宽度，上下边中手柄只改变整体高度；属性栏的整体宽、高输入同样分轴生效，不再自动联动另一轴，整体 X/Y 输入只执行平移。横纵独立拉伸以画布世界轴为目标，系统按成员角度把世界倍率映射到成员自身的局部宽高；`0°/180°` 保持同轴，`90°/270°` 自动交换轴，其他角度采用不增加剪切字段的连续近似。随后根据全部成员旋转后的可见轴对齐边界反求实际世界倍率并对齐目标组合框，不再把未旋转逻辑宽高的名义倍率直接套到旋转成员上。成员中心、尺寸和内容层 `visualScaleX/visualScaleY` 使用同一局部倍率累计，成员自身角度保持不变；相邻横竖直线或其他旋转成员在多轮横向、纵向拉伸和反向收缩后不会错位、重叠或断开，恢复原组合尺寸时位置、尺寸、角度及两轴内容倍率回到操作前结果。纯直线组合沿高度轴仍使用 `0.1px` 最小值。系统根据成员角度和每个成员距离 `20000px` 最大尺寸的剩余倍率反推组合可拉伸范围，避免旋转或超宽成员保存重开时被归一化而改变布局；移动、旋转、预览、撤销重做、取消组合和保存重开均保留两轴结果。

### 右侧属性面板

“属性”页根据选中对象显示分类属性：只有在左侧“图纸”页明确选中当前图纸卡片后，才提供文件名、画布尺寸预设、自定义宽高、背景、边框、网格和连线设置；选择组件、线稿、画布空白或其他左侧分类会退出图纸属性状态，防止组件编辑时误改画布。图纸连线设置会统一作用于已有连线和后续新连线。选中多个组件时，属性页优先显示“组合为组件 / 取消组合 / 添加为我的”、整体位置与尺寸和组合图层，不混入单个成员的专属属性，避免误改主选中节点。组件属性统一先显示基础、文字或图像和外观样式，再显示该组件专属数据，不再提供无实际用途的表单通用“数据名称/数据键”区块。基本图形包含文字、图片、视频、颜色、独立背景透明度和边框，视频可设置地址或上传本地文件、显示方式、是否自动播放、显示或隐藏视频控制器、`0.25–4` 倍播放频率、有限播放次数或无限循环以及是否开启声音；视频使用“完整显示”时产生的左右或上下留白由填充颜色和背景不透明度控制。边框宽度支持最低 `0.1px` 的实线、虚线和点线。直线使用独立的“线条尺寸”，宽度、高度直接控制可见线的长度、粗细；“线条样式”提供线条颜色和透明度、实线/虚线/点线、线段长度和间隔，以及轮廓显隐、颜色和宽度。线段的“线条样式”与直线保持相同控件顺序、字段术语和视觉布局，依次提供颜色、完全透明、不透明度、实线/虚线/点线、非实线时的线段长度与间隔，以及轮廓显隐、颜色和宽度；后续“线段属性”再提供线条宽度、独立箭头大小、起点箭头、终点箭头、端点和连接样式。新建表格默认使用居中标题、浅灰标题和表头、白色明细行、配送信息示例数据与左对齐内容；表格样式按整体与滚动、外框、内框、标题、表头、内容行分层，外框和内框分别支持实线、虚线、点线，标题、表头和内容分别设置背景或文字颜色、字体大小、字体粗细及对齐方式。表格标题使用内框的颜色、粗细和线型绘制完整四周边框，第一列表头及正文始终补齐左侧内框；隐藏标题时，首个可见行会补齐上侧内框。能与同样式外框重合的边线只绘制一次，避免出现双线。表格还可设置行列数量、表头高度、统一内容行高、每一行的独立高度、每一列的精确像素宽度、静态单元格、单双行颜色，以及横向和纵向滚动条是否显示。标题、表头和表体共同使用所有列宽之和作为内容宽度，右边缘始终一致；内容超过组件时横向滚动，组件更宽时空白保留在表格内容之外，不会拉伸用户设置的列宽。长文本可选择“自适应换行”，按设定的最小行高自动撑高；也可选择“缩略展示”，单行显示省略号并在点击后弹出完整内容。最末列和最末行会在内容轨道与外框之间存在空白，或内外框粗细、颜色、线型不一致时绘制自身内框；只有内容贴住或超过外框且两种边框完全一致时才复用外框收口，避免缺线和重复双线。属性栏以“列名称 + 内容摘要”紧凑展示前三行，点击摘要或在画布双击表格会打开可滚动的完整数据面板；“拖选合并”模式通过拖动形成矩形选区，再执行合并或拆分。“编辑数据”和“拖选合并”两种模式都按画布中的真实合并结构显示，编辑模式只在合并起始格保留输入框。合并只改变展示结构并保留所有原始值，拆分后被覆盖单元格的数据会恢复。复选框、单选框、开关和切换按钮可设置默认与当前状态；进度条支持百分比或“当前值/总数”；输入框支持默认与当前内容；选择器支持逐项增删选项以及默认选中。时间支持 `YYYY-MM-DDTHH:MM:SS`、`YYYY-MM-DDTHH:MM`、`YYYY-MM-DD`、`HH:MM:SS`、`HH:MM`、`YYYY-MM` 和 `YYYY-Www`，可展示固定时间、从固定时间开始计时或自动获取服务器时间，并可随时开始、暂停。工业、图表和网络包含数据键与状态；动效组件包含周期、方向、暂停和边框显示；自定义动效还包含效果、延迟、缓动、循环、位移、缩放、旋转和目标颜色；铅笔线稿包含精确位置与尺寸、颜色、宽度、虚线、平滑和闭合。背景可从 100% 不透明调到 0% 完全透明，不影响文字和边框。

文本组件可在右侧“文字编辑 > 内容”直接输入中文，也可在画布双击后就地编辑。两处输入都允许在焦点保持期间用 Shift、Ctrl+Space 等系统按键直接切换中英文；中文候选确认期间的 Enter 不会提前结束编辑，只有候选完成后的普通 Enter 才提交画布内联文字。右侧内容修改继续由 Vue 原生组合输入流程同步到画布，不写入拼音中间态。

文本正文中的多个连续空格会按输入数量原样显示，可用于拉开两段文字的间隔；组件边界较窄时按可用空间换行，不会把文本容器撑出组件。文本组件的“文字排布”提供横向和竖向两种模式：竖排字符保持正向并从上到下排列，高度不足时向左续列；原来的左、中、右对齐在竖排时对应顶部、居中、底部。编辑画布、普通/全屏预览、鹰眼和“我的”缩略图同步显示同一结果，保存重开后仍保留正文与排布；旧图纸没有 `textLayout` 时自动使用横向，不提升当前图纸格式版本 `20`。

时间组件的左侧时钟图标和右侧浏览器时间选择图标均有独立显隐开关。两个开关默认开启，编辑画布和预览同步生效，并随图纸、“我的组件”、撤销重做和保存重开保持；旧图纸缺少字段时继续显示两侧图标。时间文字可独立设置 `8–96px` 字号，并在常规、中粗、粗体三档之间切换；设置会同步用于编辑画布、普通/全屏预览和鹰眼。

本地视频在属性栏只显示类型和体积，不展开 Base64 全文；网络视频地址在失焦或回车后一次应用，避免选中时写入超长文本和编辑时逐字符重新加载。切换组件导致地址框失焦时，修改仍按原视频节点 ID 提交，不会写到新选中的组件。

编辑画布中的表格单击只用于选择组件，双击标题、表头、正文、空格或合并格都会直接打开完整数据面板；预览中的缩略正文仍可单击查看完整内容，两种操作不会互相抢占。

按钮组件可独立显示或隐藏“点击 N 次”徽标；点击动作设为“显示消息”时，会弹出带“确定”按钮的消息面板，消息正文由属性栏“消息内容”字段设置，编辑画布、普通预览和全屏预览行为一致。编辑画布中双击按钮进入交互后，短按继续执行计数、切换或消息动作，直接在按钮主体按住并移动超过 `4px` 则拖动组件，交互状态不会因此退出，也不需要先把鼠标移出组件；交互态按钮显示移动光标，预览中的按钮仍显示普通点击光标。

### 通信面板

顶部工具栏独立分组中的“数据源”打开工作空间级管理页。管理页右上角使用与普通预览一致的关闭按钮返回画布；“新建连接”和连接搜索固定在左侧，连接行把编辑、删除放在一起并对删除二次确认。右侧只负责启停、协议配置、保存、测试和紧凑测试摘要，不再混入点位列表、JSON 解析或组件绑定。页面统一管理 MQTT、HTTP、MySQL、SQL Server、Redis、Socket 和 WebSocket。当前网关使用纯前端示例数据完成操作闭环，不会连接真实数据库或消息服务；后续接后台时替换 `pointCatalogGateway`，界面和组件绑定结构不需要重写。

数据源配置与图纸 JSON 分开保存：浏览器按规范化后的 `workspaceId` 把非敏感连接清单和旧 `pointId` 兼容目录写入独立 IndexedDB。每工作空间的 v2 manifest 保存来源元数据、点位总数、自描述分块上限和有序 chunk key；点位默认每 `256` 条一个 structured-clone shard，key 含 workspace/source、随机 store namespace、单调 revision 和 sequence。保存先完整写入新 revision，再发布 manifest，成功后才回收旧块；失败清理本轮新块、保留上一完整 manifest，并让当前页最新状态降级为 memory-only。支持 Web Locks 时，全部默认 IDB 操作按工作空间跨标签独占，并在锁内重读 durable manifest 与有效 chunk key，避免另一页面更新后当前页仍引用已回收的旧块；不支持 Web Locks 时保留页内队列和原子 manifest 发布，但不提供严格跨标签互斥。旧 localStorage v1 整快照/v2 分片只有在 IndexedDB commit 成功后清理。修改连接名称、启停或配置可以只发布 metadata manifest，不重写未变化点位；每 4 次 IDB 操作用 `scheduler.yield()` 或 `setTimeout(0)` 让出主线程。恢复会校验工作空间、来源 ID 唯一性、chunk 归属/顺序/重复、数量、块上限和总点数；损坏时不写入默认连接覆盖。新的 `{ sourceId, revision, quality, data }` 源快照正文及其 JSONPath 派生值只存在于运行内存，不进入图纸、撤销历史或本地连接配置。密码、令牌、授权请求头、URL 凭据和最近响应正文不会明文落盘；同一页面内切换工作空间仍可暂存这些字段，刷新页面后需要重新输入。浏览器 IndexedDB 仍只是纯前端演示存储，不是生产凭据仓库；生产连接、凭据和快照路由应由后台按服务端会话授权，前端只持有不透明的数据源 ID。未来改接后台时由 `backend.js` 装配同接口网关，画布和管理页面无需改写。

首次激活或刷新十万级兼容目录时，`pointCatalogGateway` 不在一次同步调用中完成规范化和索引。`pointCatalogPreparation` 按默认 `4ms`、最多 `4096` 次操作/片构建私有来源列表、来源/点位 Map 和健康/离线统计，发现重复 ID 或异常即拒绝；新 generation 取消旧任务，全部 ready 后才一次安装。可见页面使用 rAF，隐藏页面切到 timer，避免后台标签页因 rAF 暂停永久无法激活。分片保证交互可让步，不把总 CPU 时间描述为物理零耗时。

具体使用顺序为：先进入“数据源”新建、保存并测试连接，再选中一个画布组件并打开右侧“通信”；点击需要动态控制的参数，例如“显示文字”“填充颜色”“进度数值”或“表格数据”；选择数据源，在最新样例 JSON 树中点击字段或手动填写 JSONPath；核对解析值、类型和“数据源 → 参数”关系后点击“建立绑定”。选择字段不会自动写入关系。已连接项直接显示来源、路径和目标参数，可在原处更换或解除。未选组件、多选组件或锁定组件时不会误改绑定。

通信页的参数定义来自 `componentBindingSchema.js`，与属性页编辑的是同一组节点字段。属性页负责静态默认值，通信页新建关系保存为 `{ target, sourceId, jsonPath, enabled }`，可选 `adapter` 只用于受控转换；旧 `{ target, pointId }` 图纸继续兼容。安全 JSONPath 只支持根、对象自有字段和数组下标，不执行表达式、过滤器或用户 JavaScript。文字接受标量，颜色接受颜色值或约定状态词，数值和布尔按安全规则转换，表格接受 `{ columns, rows }` 或行数组。路径无结果、来源不可用、格式不合法或尚未收到值时继续显示属性中的静态值；选字段和最终提交各校验一次。动态值只在 `runtimeNodeMaterializer` 生成的视觉副本中覆盖，编辑画布、普通预览、全屏预览和鹰眼共用该结果，不写回节点、JSON 或撤销历史。

停用连接、检测中、数据滞后、连接离线、测试失败或删除连接时，源快照质量立即变为不可用，相关派生值发布 `undefined`，已绑定组件自动回退到属性中的静态值；恢复正常后按最新快照重新求值。通信页用 `shallowRef` 保存只读快照，JSON 树只枚举展开分支，默认单层最多 60 项、总可见 240 项、深度 12 层。`sourceBindingRuntime` 以 `sourceId -> 唯一 JSONPath` 增量登记引用，相同源和路径每个 revision 只求值一次，高频更新只保留最新快照并按每片 `2ms/256` 项发布；大图整体换图时按帧重建源索引，重建期间发生的绑定新增、修改和删除在提交时合并，旧扫描结果不会覆盖新编辑。组件数量增加不会产生同等数量的协议请求或 JSON 重复解析。运行时表格最多物化 `50 行 × 12 列`；每个嵌套单元格最多读取 4 层、12 个对象键、12 个数组项和 48 个总条目，最终文字不超过 256 字符。默认快照读取保持隔离副本，编辑器内部显式使用只读共享引用，真实采集适配器可以移交已解析 JSON 所有权，避免大响应重复深拷贝。

数据源测试或恢复后统一用 `{ sourceId, data, revision?, quality? }` 快照刷新运行值。不同数据源并行恢复且互不取消；同一数据源只允许最新请求提交。结构不匹配、来源不一致、已失效或跨工作空间迟到的快照均不得进入运行时；动态出现的旧 `pointId/dataKey` 只按当前组件引用定向恢复。

整张图纸共享数据源快照流和运行网关，组件不能各自建立协议连接。真实协议先转换为 `{ sourceId, revision, quality, data }`，由 `sourceBindingRuntime` 按 JSONPath 派生为 `{ key, value }[]`，再经 `runtimeUpdatePipeline` 和 `useRuntimeData` 发布到活跃叶子。生产消息必须由服务端按已认证的租户、工作空间和图纸路由；大 JSON 在 Worker 解析，SQL/HTTP 大结果必须分页、筛选或聚合，协议端同时限制消息字节数。

### 布局与结构面板

布局面板提供水平居中、垂直居中、置顶和适应画布。结构面板按统一图层顺序列出节点与铅笔线稿，可选择被其他对象遮挡或已锁定的对象。文本组件在结构列表和属性面板顶部都固定显示类型名称“文本”，不会把可能很长的正文当作组件名称；正文只在属性面板“文字编辑”的内容项中展示和修改。锁定只禁止直接编辑，不改变对象所在图层；高图层对象始终遮挡低图层对象，无论其类型或锁定状态。

### 预览模式

预览模式隐藏编辑手柄和属性面板。普通预览可切换 `1:1` 原始像素模式和自适应模式：原始模式从内容区左上角 `(0,0)` 布局，画布超出窗口时通过横向和纵向滚动；自适应模式等比显示整张图纸。预览导航栏的“全屏预览”使用浏览器原生 Fullscreen API，请求隐藏浏览器导航界面；进入全屏后不再渲染文件名、画布尺寸、自适应、全屏和关闭按钮所在的普通预览标题栏，也不显示额外的退出按钮，只保留画布内容。全屏只扩大显示区域，始终强制 `scale(1)` 按图纸实际 CSS 像素从左上角显示，不做放大或缩小，超出屏幕时通过横向和纵向滚动查看。全屏元素、尺寸和状态通过 `fullscreenchange` 同步；按 `Esc` 先退出浏览器全屏，再次按 `Esc` 才关闭普通预览。每次进入预览会按表单的默认值初始化状态；复选框和开关可以反复开启、关闭，单选框再次点击可取消，同组单选框在选中时仍保持互斥，进度条、按钮、输入框、选择器和时间控件均可真实操作，交互值会写回当前图纸状态。编辑画布中双击表单组件可进入交互状态，再次单击控件即可就地查看和修改效果；双击表格直接打开完整数据面板。视频设置为自动播放时，进入预览后立即开始播放；关闭自动播放时保持暂停，需要由用户手动播放。视频控制器可独立显示或隐藏，显示时可手动播放、暂停、调整音量和定位进度；隐藏控制器时可单击视频区域或使用 Enter、空格切换播放和暂停。播放速度、次数和声音继续使用属性中的设置。运行中的计时或服务器时间组件每秒更新，表格按结构化标题、表头、行列静态内容和样式展示。风机、管道、信号灯、水箱、心跳、粒子、仪表和图表等动画在预览中运行，实时数据值同步展示。内置动效组件采用全区域视觉，不附加右侧说明文字。

动效在编辑画布中也会直接播放，便于边编辑边检查。动画只作用于节点内部视觉，不改变节点外层坐标、选框和旋转手柄。风机使用静态外壳与独立转子，只有叶片转子旋转。

“自定义动效”分类提供自定义图形、动态文字、动态图片和自定义指示器。可组合弹跳、水平移动、旋转、缩放、淡入淡出、颜色变化以及周期、延迟、缓动、循环和方向参数，不需要直接编写 CSS。

### 文件与数据

顶部“打开”默认读取项目根目录 `图纸库/` 的文件列表；每次选择文件都会重新读取、准备并应用磁盘 JSON，即使左侧已经存在同名图纸会话，也会用磁盘最新内容替换该会话并保留其列表位置。列表中的删除命令仅针对项目图纸库，需要二次确认并用列表 ETag 校验文件版本；删除成功或明确确认文件不存在时，已打开内容保留但文件身份改为“未保存”。删除失败后不会根据刷新列表缺少该项直接解绑：只有 DELETE `404`，或不解析内容的 HEAD 探针返回 `404`，才确认文件不存在；探针故障时保持绑定。“打开其他位置”可读取用户选择的图纸文件，项目图纸库删除不会操作这些文件。顶部“保存”和 `Ctrl+S` 使用同一链路，并始终从当前激活会话取得图纸数据、撤销历史和文件身份：已打开的默认目录文件保存回原文件，新图纸以当前图纸名称写入 `图纸库/`。未保存图纸的规范化文件名若已存在于图纸库，左侧卡片显示“未保存 · 同名冲突”；两个未保存会话指向同一规范化目标时显示“未保存 · 同名目标”；卡片同时展示完整 `图纸库/<名称>.json` 目标，tooltip 分别解释磁盘冲突或会话冲突。“另存为”可写到用户选择的其他位置。左侧图纸分类中的删除仅关闭前端编辑会话。文件内部采用统一的版本化 JSON 图纸结构，当前版本为 `20`；版本 `6` 起带有 `projectId`、`revision` 和时间信息，版本 `18` 增加节点 `groupId` 与图纸级 `customComponents` 自定义模板，版本 `19` 把旧铅笔线稿迁移为普通 `pencil` 节点，版本 `20` 迁移旧直线几何。

完整多图纸工作空间会话由 IndexedDB 按工作空间保存，包含活动图纸、各图纸内容、文件身份和撤销/重做历史；成功撤销或重做后也会重新调度快照。内存 LRU 的目标容量为 3，但只允许淘汰最新快照已成功落盘的最旧工作空间；IndexedDB 失败或新版本仍在保存时保留脏会话，并发旧保存迟到不能误标最新状态。自动快照在输入空闲且没有指针、文件或交互提交任务时启动，会话正文再以默认 `4ms` 时间片编码为 `64KiB` Blob chunks，待处理输入优先让步；IndexedDB 只原子提交包含 Blob 引用和句柄元数据的小 envelope，不再同步克隆整份图纸对象。保存版本在编码期间、写入前和写入完成后门禁，过期快照不能被当作最新状态，损坏 chunk 或越界句柄路径也只产生受控恢复失败。旧 object 快照继续兼容，自定义句柄不可克隆时保存无句柄降级副本。

显式文件保存和工作空间切换取消自动 idle 任务并直接等待完整会话持久化。切换开始后，系统先结束线段拖动、待提交缩放、滚动、连接和指针操作，等待交互提交完成，再等待已经开始的异步组件包捕获/插入和图片/视频读取结算；随后保存旧工作空间、恢复新工作空间。整个过程用不可交互界面和透明屏障阻止第二条命令。组件卸载会先失效生命周期、取消媒体与组件包任务，再释放异步屏障、解析器和会话仓储，迟到的 Worker/fallback/FileReader 回调不能写回；卸载导致的解析取消也不会误删合法 localStorage。恢复时逐张过滤损坏图纸，全部无效才删除坏快照并回退兼容路径。`localStorage` 只保存当前活动图纸的小型兼容副本；它以默认 `4ms` 时间片和最长 `4KiB` 字符串片段有界编码，超过约 4 百万字符时立即早停并删除旧 key，不影响 IndexedDB 或正式文件。跨标签更新与保存冲突只在 Worker 中读取 `projectId/revision/updatedAt`，不把完整图纸克隆回主线程。文件保存成功后才更新当前文件身份、修订号和时间。首次保存的新图纸与库内文件同名时拒绝创建并提示名称冲突；已打开文件携带旧 ETag 时提示版本冲突。两种情况都不会静默覆盖图纸库中的现有内容。运行时数据与图纸文档分离，不进入撤销历史、恢复缓存或图纸文件，并在切换图纸时清空。

本地图纸库的单图读写上限默认是 `256 MiB`（`268435456` 字节），启动前可用正整数环境变量 `TC2D_MAX_DRAWING_BYTES` 覆盖。服务在磁盘 stat 后、`readFile` 前检查大小：超限文件不进入图纸列表，直接打开返回 `413`；保存前的已有文件冲突校验和删除读取也执行同一门禁。限额检查早于 metadata 缓存命中，配置调小后不能继续使用旧缓存绕过。`PUT` 同时预检 `Content-Length` 并流式累计 chunked 请求，超限返回 `413`，压缩请求体被拒绝。图纸列表、读取、保存、删除和 HEAD 存在性探针都不使用通用 `15s` 固定超时；浏览器“其他位置”不经过本地图纸库 API，但仍受浏览器和设备能力限制。

前端导入和本地文件服务共用结构容量校验：画布节点与旧临时线稿合计不超过 10,000、连线不超过 20,000、旧临时线稿不超过 5,000；顶层和“我的”模板中的铅笔/线段路径连同旧线稿点合计不超过 250,000，单条顶层或模板 `polyline` 最多 10,000 点；“我的”最多 200 个模板，全部模板合计不超过 2,000 个节点和 4,000 条内部连线。模板几何、重复 ID 和悬空连线也在共享契约中检查，不会由一端静默截断。单个本地视频仍限制为 20MB，该规则只约束媒体上传入口，不代表整张图纸上限。

图纸列表按文件 stat 签名复用已验证的 metadata/ETag，直接打开可登记当前缓存；保存后重新读取并核对期望 ETag，验证前后均失效缓存，删除也主动失效，避免并发列表留下陈旧条目。同一签名下确定为 `422` 的无效 JSON/结构使用负缓存，文件变化后重新校验，临时 I/O 和读取竞态错误不缓存。图纸库、其他位置和 localStorage 兼容恢复中的 JSON 字符串由 `projectJson.worker.js` 执行 JSON 解析、结构/容量校验、旧版本迁移和模型归一化，再把四个实体集合按最多 `128` 项、目标约 `1MiB` 的协议分块回传；主线程校验序列和总数后组装。Worker 不可用、创建/发送失败、崩溃或消息错误时统一回退同一主线程操作，所有 pending 请求都会结算。组装后的项目数据还要经过 `projectRuntimePreparer`：主线程按默认 `4ms` 时间片建立完整私有运行索引，全部 ready 后再一次安装；高出度拖动松手后的三索引压实则使用独立 `2ms` 任务。

### 后台接口预留

当前版本仍由 Vite 本地文件服务提供同源接口，不代表账号、数据库或生产后台已经完成。`App.vue` 通过服务边界调用数据：图纸列表/读取/保存/删除及 HEAD 存在性探针进入 `drawingRepository`，服务器时间进入 `timeService`，连接和源快照进入 `pointCatalogGateway`，JSONPath 派生进入 `sourceBindingRuntime`，最终运行值进入 `runtimeGateway`，画布历史检查点进入当前为空实现的 `operationGateway`。HTTP 基地址统一由 `VITE_API_BASE_URL` 控制，默认空值保持现有同源请求。

图纸仓储保留现有 ETag 规则：新建发送 `If-None-Match: *`，目标名称已存在时返回 `412` 并提示同名冲突；覆盖和删除发送精确 `If-Match`，旧 ETag 同样返回 `412`，但保存提示明确说明图纸库版本已被其他操作修改。HTTP 条件失败状态保持一致，业务提示按创建冲突和版本冲突分开，且都不能静默重试覆盖。`backendRequestContext()` 统一提供 `workspaceId/projectId/revision`，当前本地适配器有意忽略这些字段，因此本地 URL 和现有文件行为不变。生产适配器可把上下文映射到后台资源路径或请求体，但用户、租户和权限必须来自服务端验证后的会话，不能采用前端可修改的字段。

数据按用途分离：图纸快照只保存组件及 `dataBindings` 规则；操作事件用于可选的低频审计或协作协议；连接配置描述采集方式；源快照和派生运行值只用于高频展示且不进入撤销历史和图纸文件。浏览器“打开其他位置/另存为”继续使用用户授权的文件句柄，与服务器仓储保持独立。未来接后台主要替换 `backend.js` 和 `pointCatalogGateway.js` 的适配器并复用 `sourceBindingRuntime/runtimeGateway`，不应把请求重新写回组件或画布事件处理函数。

### 大图性能

编辑画布、原始尺寸预览和全屏预览使用均匀网格空间索引查询当前视口附近的节点，不再在滚动、缩放或框选的每一帧扫描全部组件。超过 1,500 个节点时，额外视口缓冲由普通图纸的 `240px` 收紧为 `96px`；低倍率或超大范围查询改为遍历实际占用的网格桶，并先用整图内容边界拒绝完全无交集的请求。节点移动、缩放、旋转和位置输入只增量更新受影响的索引项。

节点、时间、图层、空间和连线邻接均使用持久增量索引。普通新增只从响应式数组尾部登记本批 Vue 代理，只把时间节点加入 `timeNodeIndex`，只更新本批空间桶和连线端点；删除及实体撤销同步增删对应记录，只有打开、切换或整体恢复图纸时统一重建。表格、文字等按 ID 恢复编辑对象的入口直接查询 `nodeIndex`，不扫描完整节点数组。

高出度节点的移动不会在每个指针帧更新全部连线。相邻边计数超过 `128` 后，当前帧直接停止邻接枚举并标记索引需要重建；Canvas 几何 payload 和 SVG 活动边也统一限制为 128 条。松手并结束交互屏障后，后台调度器在主线程按 `2ms` 时间片建立私有节点空间、连线空间和邻接索引，验证文档版本与交互代次后一次原子替换；重建过程中当前索引继续服务查询，不会暴露半成品。

图层使用 `committedMax/reservedMax` 双游标：普通新增以常数成本预留一个或一批连续层级，预留失败也不回收编号；提交只检查本批实体。`layerEntries` 保持增量有序，正常高层新增直接追加，历史恢复旧层级时二分插入。右侧“结构”面板按固定行高计算窗口，并通过 `entries.length - index - 1` 从尾部反向取行，数千图层时既不挂载全部 DOM，也不创建完整倒序数组。

复制、粘贴和“我的组件”实例化统一进入组件包事务。包不超过 64 个节点且不超过 128 条内部连线时保留同步快路径；超过任一阈值后，捕获、排序、ID/组合映射、模型归一化、响应式实例、历史计量和私有索引都按 `2ms` 动画帧分片。常用模板及剪贴板包在空闲帧预热一次性实例，命中后只预留本批图层、附加私有索引、向 raw 实体数组尾部写入并统一发布；冷大型包先立即显示目标占位框，准备完成后原子替换。2,000 节点预热实例发布到已有 6,016 节点文档的同步段约为 `10.68～13.73ms`；冷准备 CPU 总量约 `202ms`，分片后的墙钟完成约 `1.7s`，因此“零延迟”表示操作立即得到反馈和可编辑结果，不表示物理 `0ms` 完成全部构建。

`interactionCommitBarrier.js` 用活动键和单调 `generation` 覆盖指针、连续缩放、滚动、连线及线段起点拖动。组件包捕获/发布和索引压实同时携带文档版本与交互代次；任何用户交互跨过后台任务生命周期都会拒绝旧提交。需要恢复的任务按 key 合并，只在全部交互结束后的干净动画帧重试，避免后台任务在一次活动手势中替换索引或发布半成品。

连续滚轮采用两阶段缩放：滚轮热路径按动画帧累计档位，不逐帧发布 Vue `zoom`。目标视口仍在当前渲染覆盖范围内时，只修改舞台占位尺寸、合成变换和滚动位置；向外缩放露出新区域时，以空间索引查询当前与目标世界范围的并集，只增量挂载新增节点和线稿，并在 DOM 更新后应用变换。最后一次滚轮停顿 `96ms` 后，先提交实际视口、再一次发布 Vue `zoom` 并清除临时并集。该过程不全量扫描图纸、不刷新鹰眼、不卸载手势期间已经挂载的节点，也不逐节点修改反向尺寸变量。复杂表格、表单、进度、铅笔和线段的序列化渲染键使用 `WeakMap + computed` 按节点缓存，只在对应字段变化时失效。节点达到 1,200 且倍率不高于 30% 时，编辑态由整图 Canvas 承载静态内容，仅为活动对象保留最多 128 个 DOM；普通自适应预览也使用分片 Canvas，不再因显示整张图纸而挂载全部节点 DOM。低倍率编辑的专用网格背景位于 Canvas 下方，透明交互 stage 位于 Canvas 上方但不绘制网格；普通线条和点阵网格选择器必须排除 `.editor-lod-stage`，避免低倍率时第二份网格覆盖组件。

大图加载、退出预览或完整 LOD 退出后，普通倍率首屏超过 `128` 个节点时不会一次挂载全部 DOM。系统先保持 Canvas 画面，再按每帧最多 `8` 个节点和 `64` 挂载成本渐进恢复 `NodeVisual`，全部完成后退出临时 LOD；打开预览会取消尚未完成的编辑挂载帧。普通倍率视口节点不超密但连线超过 `1,024` 条时只启用 edge-only Canvas：Canvas 绘制全部连线，节点、表单、媒体、动画、铅笔和线段继续保留完整 DOM 交互，活动 SVG 边最多 128 条。该模式不把 Canvas 扩大成节点或线稿替代层，也不在完整边帧提交后保留只服务节点运行值的 static/composite 双离屏面。

多选成员超过 128 个时，指针移动期间只更新组合操作框的临时边界，不逐帧改写每个成员。抬起后由 `largeSelectionTransform.worker.js` 计算最终移动、缩放或旋转几何；Worker 创建、发送或运行失败时，主线程必须进入等价的 `2ms` 可恢复任务，不能同步遍历整个选区。结果实体、节点空间索引和相邻连线索引同样按 `2ms` 分片提交；透明屏障在 raw 几何、索引和历史全部一致前阻止第二条指针或键盘命令，最后只发布一次响应式引用。

单个表格含表头在内超过 `120` 个单元格时，编辑与 DOM 预览只挂载当前滚动窗口，并保留上下 2 行、左右 1 列缓冲；固定行高和自动换行动态行高都保留完整滚动尺寸、末行末列和跨窗口合并区域。原始尺寸与全屏预览的节点递增挂载还同时受节点数和类型复杂度预算约束；工具默认批次为 128 个节点、成本预算 1,024，主预览实际使用 8 个节点、成本预算 64，复杂表格不会与普通节点按相同成本集中塞进一帧。

拖拽、旋转和数据更新按浏览器帧合并，历史栈不再同步序列化整张图纸。连续几何操作只保存受影响对象；属性和表格保存字段差异；图层和模板列表保存顺序差异；新增、复制、粘贴、模板实例化、完成铅笔/线段、建立连线及删除对象只保存本批节点、连线或旧线稿的 `{ id, index, value }` 实体差异。实体历史通过 `reuseEntityReferences` 复用已归一化引用，按目标 ID Map 提前停止查找，连续区间只做一次 `splice`；raw 数组完成批量变更后每个集合只触发一次 `triggerRef`，删除后的图层条目稳定压实，历史字节计量使用 WeakMap 缓存。正式图纸前 2,000 个节点的 10 轮样本中，删除历史捕获为 `3.99ms`，一次早期样本的 Undo/Redo P95 为 `9.506ms/4.354ms`；最终两次复跑的 Undo P95 分别为 `15.809ms`、`14.627ms`，Redo P95 分别为 `11.024ms`、`6.008ms`，均低于 `16.7ms`。实时数据只使相同 `dataKey` 的节点失效。

鹰眼、低倍率编辑和自适应预览都复用分片 Canvas 渲染器。完整刷新会创建私有离屏 Canvas，把节点索引、连线、实体准备、归并排序和绘制拆成有预算的小任务。激活的自适应预览使用 `MessageChannel` 的 `task` 模式，每片最多 `4ms`；编辑高清 detail 同样使用 `task` 模式且每片最多 `6ms`；`MessageChannel` 不可用时两者退回 `setTimeout(0)`。非活动 bootstrap 和鹰眼使用空闲调度且每片最多 `2ms`，低清编辑 fallback 使用逐帧 `2ms`。完整帧调度器会在每个 slice 开始读取当前 `renderBudgetMs`，运行值调度器保持固定 `2ms`；创建、执行、调度或提交异常都先释放失败任务，再统一进入 Canvas 错误上报和 DOM/完整帧恢复，不会留下未处理的调度回调异常。

低倍率编辑只在 Canvas 下方绘制专用网格，普通交互 stage 不再绘制第二份网格；视觉网格按倍率自动抽稀，屏幕间距至少 `8px`，网格线宽和点径至少 `1px`。整图 fallback 限制为 `1,048,576` 像素；当前视口 detail 以 `3x` 为目标 backing，并受 `12,582,912` 像素上限保护，预算不足时先缩减不可见缓冲，再有界降低实际倍率。detail 的节点描边、连线、铅笔和线段同样保持最低 `1px` 屏幕线宽。已有高清帧变旧时继续显示并与内部网格一起按 committed frame 投影，新完整帧完成后再原子替换；旧帧只是 stale 过渡，连续放大时有效密度会暂时下降。移动、缩放、旋转和删除只把旧/新边界局部 patch 到 fallback 与 detail 两张 Canvas，不先退回低清整图，也不为单个变化同步重绘全图。几何开始会使旧运行值工作面和 back surface 失效；操作取消后，有合法增量基线时立即重放待处理运行值，没有基线时请求完整帧，完整几何帧提交后仍继续收敛交互期间到达的数据。detail 局部 patch 退化时，只把 fallback 已可靠提交且与高清帧相交的局部边界通过基础 `polygon(...)` 默认 nonzero 环绕透明挖出，孔洞外的背景、网格、文字和组件继续使用高清 detail；即使浏览器不支持基础裁剪，也保留高清帧和活动组件等待完整帧恢复，不再整窗降级。

低倍率 detail 为清晰度提高文字屏幕字号时，先按节点保存的原字号生成横排换行或竖排列基线，再用基线内容宽高限制最终字号，并直接复用同一组行/列绘制。组合通过 `visualScaleX/visualScaleY` 放大后，文字仍保持原布局结构，不会因可读字号二次换行而把多行压叠到一起。正文 `String.length > 512` 时不在单个实体调用中同步完成全部字素拆分、换行和测量：full、dense 与 sparse 三条路径都保留当前实体游标，通过 `incrementalTextLayout.js` 每 32 次操作检查调度截止时间，并以每片最多 8,192 次操作作为无截止时间时的硬上限；布局完整后才把文字绘入私有 surface 并推进游标，可见 Canvas 仍只接收完整帧。任务被新世代取代或取消时清除未完成布局；测量或绘制异常时 surface 标记为不可复用并进入既有错误恢复。几何局部 patch 遇到同类长文本时直接退回权威完整帧，不在指针提交路径同步跑完整布局。

拖动节点超过 `4px` 后，活动组件会以原透明度乘以 `0.62` 显示，便于看清放置位置下方的设备、文字和网格；普通 DOM、低清 fallback 和高清 detail 的效果一致。该效果只存在于当前拖动帧，不会修改图纸属性、撤销历史或保存文件；松开、取消、失去捕获、窗口失焦、异步大选区提交和切换工作空间都会立即恢复。连续删除产生的局部透明区域最多保留 `32` 个分离矩形，超过上限时按最小新增覆盖面积压缩，避免把相距很远的删除位置扩成遮挡整图的大矩形。

活动自适应预览按最终显示面积以 `max(2, min(3, devicePixelRatio))` 为目标倍率，位图上限为 `8,388,608` 像素；非活动 surface 仅作为装载 bootstrap，位图上限为 `4,194,304` 像素。小窗口不会固定占用最大位图，超大活动视口触及总上限时会有界降低实际倍率，但只有预算计算的可达像素比和完整帧实际像素比都达到请求值才允许 Canvas 交接；否则继续使用清晰 DOM，edge-only 则恢复完整 SVG。新请求取消并释放旧世代，旧回调不能提交；只有当前世代完整完成后才原子替换可见 Canvas。自适应模式把视频、表单、表格、时间控件和持续动效归为 live 节点。系统从最高图层向下最多读取 `24` 个 `layerEntries`，找到覆盖全部 live 节点的最短完整尾段；该尾段可以包含静态 node 和 drawing，整体由独立的持久 `preview-live-plane` 挂载。Canvas 通过 `excludedNodeIds` 与 `excludedDrawingIds` 排除尾段，只绘制其下方静态前缀并保留节点端点索引；edge 只由 Canvas 绘制，尾段 drawing 只由 DOM/SVG 绘制。无法在 24 条内证明安全尾段时回退完整 DOM；纯静态图在 Canvas ready 后卸载 DOM。live plane 独立于完整 DOM stage，在 fit、原始尺寸和全屏交接期间保留尾段实例，避免视频、表单和动态状态整批重建。

原始尺寸与全屏的 edge-only Canvas 把请求 DPR 写入计划键，并保存已提交范围、计划键和完整帧 X/Y 实际像素比中的较小值。完整帧写入可见 backing 前，`frameCommitGuard` 先校验路径仍活动、事件计划/范围仍等于当前请求且实际 DPR 达标；显示时再校验 committed 计划/范围/DPR 及对当前视口的覆盖。设备 DPR 提高、视口窗口或边修订变化后，旧 Canvas 不再接管，完整 SVG 连线继续渐进显示到新的清晰帧提交；迟到旧计划或旧范围帧直接忽略且不清当前 ready。若当前匹配请求的实际 DPR 不足，则停用本次 edge-only 并完整恢复 SVG，不会留下缺边或被放大的低密度背景。

正常等待可用且清晰的 fit Canvas 时，完整 DOM stage 只取当前带缓冲视口节点；只有 Canvas 计划不适用或 `previewFitCanvasFailed` 已置位时才请求完整图纸 DOM。`ProgressivePreviewNodes` 新世代会立即剔除目标外陈旧节点并用最新同 ID 引用替换保留项，缺失项通过原地 `push` 扩展同一数组；每批在 `nextTick` 后按真实提交耗时把倍率在 `1–16` 之间加倍或减半。`PreviewNodeBatch` 的 `v-memo` 包含节点引用，稳定 key 不会阻止对象替换刷新。Canvas 失败时页面先切回原尺寸 DOM，完整图纸 DOM 渐进 ready 后才进入 `dom-fit`，不会在 Canvas 等待期间预先挂载全图，也不会显示低密度或空白画面。原始尺寸和全屏预览返回完整视口节点、连线和线稿，不使用 `512/1024/512` 阈值裁剪实体；这些阈值只触发提前预备 Canvas 装载帧。视口变化时不再属于目标的 DOM 立即释放，交集中的媒体、表单和运行值订阅保留；原始尺寸或全屏 DOM ready 后卸载无用的 fit Canvas。`previewFrameFreshness.js` 进一步区分文档、请求和提交世代：fit surface 启动或目标变化后请求属于自己的权威完整帧，不显示从其他 surface 复制的低密度帧；文档修改推进世代并使旧帧失效，只有匹配文档 token、目标尺寸、请求像素比和渲染计划的完整帧提交后才建立 available/fresh。运行值局部帧不能越过未提交的新文档帧，连续到达的 `pendingRuntime` 也不能使已经合法提交的 Canvas 永久无法交接。没有运行视觉可绘制时仍发送 settled no-op。首次 Canvas 提交同时保留不含运行值的静态底图，后续设备值通过 `dataKey` 反向索引进入 latest-wins 脏集合，只恢复并重画相交脏矩形；同一批脏节点由页面统一取出后分发给编辑与预览 Canvas，不能由两个消费者相互清空。时间节点由独立索引局部刷新，不每秒扫描整图。全屏尺寸由独立调度器合并 `fullscreenchange`、`ResizeObserver` 和滚动：首帧没有观察尺寸时仅等待一次，第二帧才读取 DOM 兜底，普通滚动不增加延迟。

完整 DOM 回退不是只渐进节点。`ProgressivePreviewGeometry` 会保留当前世代仍存在的稳定不可变 edge/drawing 批次并替换为最新同 ID 引用，缺失内容首帧分别最多挂载 `64` 条连线和 `8` 个线稿，之后按 `nextTick` 实际提交耗时逐帧增长，倍率最多为 `4`；端点和线稿路径也随对应批次计算，不在一帧创建完整 SVG。页面分别维护节点 ready 与几何 ready，且完成事件必须匹配当前世代和当前数量；两者同时完成后，`finishPreviewDomHandoff()` 还要确认预览仍打开、DOM stage 仍挂载且目标仍为 `dom`，才把完整 DOM 视为 ready 并切换 `dom-fit`。关闭预览会先递增 `previewDomGeneration` 拒绝迟到完成事件，因此降级过程不会提前暴露半张图或在关闭后反向切换。

运行值 Canvas 的页面队列每个动画帧最多取出 `1 × 512` 个节点，并把同一 `{ nodes, dense, pending }` 广播给活动的鹰眼、低倍率 fallback/detail 和自适应预览。满批且仍有后续数据时开启 dense stream；最终批以 `pending: false` 关闭流，整数批边界或去重产生的空终批也会完成最终收敛。Canvas 先排除当前局部帧之外的运行节点；本批没有可见变化时只发送 settled no-op，不创建工作面或提交零脏区。内部在节点不少于 `1,024`、脏区多于 `64` 或位图覆盖率达到 `35%` 时选择 dense，否则使用 sparse。sparse 在 front/back 两张已提交合成面之间轮换，下一帧只同步上一批 dirty rects；没有可复用 back 时才对完整工作面分条 seed。dense 始终从静态底图按真实图层重放。两种模式都在私有工作面中按 `2ms` 分片，必要的初始 seed 按最多 `262,144` 像素一条执行 `clear + source-over`。大量时间组件直接走空节点 dense 请求，避免每秒先遍历完整时间节点数组。

完整帧、运行值帧和几何局部帧最终都由 `canvasSurfaceCommit.js` 写入可见画布。尺寸不变的全量帧只执行一次 `copy + drawImage`；局部帧把全部脏矩形组成一个 union clip 后仍只执行一次 draw。全量帧需要改变 Canvas backing 尺寸时，提交前保留可恢复旧帧；新 context、token 或新帧 copy 失败会恢复旧宽高和旧像素，回滚资源始终释放。不再先清除可见区域再逐块绘制，因此任务被取消、context 失效或 draw 异常时不会主动留下白块或逐块半帧；几何内部合成失败会使几何索引失效，并由既有 fallback/完整帧恢复。

安全尾段除最多 `24` 条的层级门禁外，还有单批挂载门禁：尾段 node 最多 `16` 个，node 与 drawing 的总成本最多 `128`，drawing 每个计 `4`；任一超限都改用完整 DOM。视频成本为 `32`，GIF/APNG/WebP 动态图片为 `24`，`custom*` 或非 `none` 动画为 `12`，普通节点为 `8`，select 和 table 按选项或单元格规模增加。Canvas 完整 `render-complete` 会携带任务的 `renderPlanKey`、`excludedNodeIds` 与 `excludedDrawingIds`；页面仅在计划 key、两组有序 ID、freshness 与请求像素比都匹配后，提交 committed overlay 节点和 drawing 快照。这样 live 分类或图层在渲染途中变化时，旧帧不会短暂造成重复或缺失。Canvas context 丢失、不可用、像素比不足或提交 token 失效时会发出/进入 `render-error`，先回退原尺寸完整 DOM；完整世代 ready 后才进入 `dom-fit`。context 恢复后按新世代重绘，用户不会看到空白或模糊 Canvas。关闭预览、切换原始尺寸或进入全屏都会清除 committed plan；原始/全屏 DOM ready 后继续释放无用 Canvas surface。除 `fullscreenchange` 外，`resize`、`focus` 和 `visibilitychange` 也会依据 `document.fullscreenElement` 幂等校准全屏状态。

Canvas surface 只有在首次和释放前都能取得 2D context，且任务外层 `save()/restore()` 成功配对时才进入复用池；坏 surface 会被清空隔离，不能污染后续帧。节点、填充、图片裁剪、铅笔、线段、设备内部变换、临时线稿、边 marker 和几何局部合成都用 `try/finally` 配对嵌套 Canvas 状态，任一内部绘制抛错都不会把 transform、alpha、dash、clip 或 lineCap 泄漏给下一实体。主 surface 或静态 surface 在任务创建期间若于 `save()` 后抛错，会先恢复已保存状态，再以不可复用方式释放尚未归属任务的 surface；runtime seed 的 draw/null-context 以及取消清理中的 restore/reset 任一步失败也会隔离工作面。geometry 获取 static/composite/target context 抛错或 backing context 为空时统一报告 `geometry-commit-failed` 并请求权威完整帧。专项异常注入 `18/18` 覆盖上述路径。同一动画帧内多个图片成功加载事件合并为一次重绘，图片失败不触发整图更新。隐藏的 fit surface 通过 `active=false` 取消 full/runtime、时间与图片调度，只记录最新 dirty；重新成为显示目标后只追赶一次，避免后台 Canvas 与画图和接数争抢帧预算。

这不是任意的 Canvas/DOM 混排。系统只允许“Canvas 静态前缀 + DOM 完整尾段”这一种可证明层级正确的结构，并在不能证明时优先回退 DOM。全 DOM 对大图挂载压力更大，全 Canvas 又无法保持视频、原生表单和持续 DOM 状态，多个交错 DOM 岛还会扩大排序、事件命中和交接竞态；当前有界尾段方案在显示正确、交互完整和预览性能之间风险最低。剩余风险主要来自单屏本身同时存在大量复杂媒体/动画、极复杂 SVG path 或目标设备 GPU/context 稳定性，这些场景由成本门禁、context 回退和目标设备专项验收控制，不能仅凭已有平均性能数字放行。

源快照先由 `sourceBindingRuntime` 按 `sourceId + JSONPath` 聚合；同一 revision 的相同路径只解析一次，大绑定索引通过可取消分片重建，高频快照只保留最新版本。派生结果再在协议适配器与 `useRuntimeData` 之间经过 `runtimeUpdatePipeline`：小批可使用同步规范化和同步发布快路径；大批按默认 `2ms` 与项目数双预算公平轮转，批次 sequence 保证批内及跨批同 key latest-wins。已知长度批次入队即占用容量，未知 iterable 先占首槽再逐项记账；总 pending、单批项目、键长度、字符串值和二进制值均有上限。sink 只有成功返回后才提交去重状态，异常保留 chunk 重试；停止和重连通过 generation 隔离迟到回调。生产接入还必须设置消息字节上限并优先发送变化键；真实大 JSON 的解码、`JSON.parse` 和结构校验应在 Worker 完成，不能放入画图主线程。

DOM 叶子和 Canvas 在展示运行值前统一调用有界格式化器：默认输出不超过 256 个字符、嵌套不超过 4 层、对象和数组分别最多读取 12 个键或项目、整个值最多读取 48 个条目，并处理循环引用、抛错 getter、异常代理和超大 BigInt。性能探针同样保持有界，最多保留 4,096 个帧间隔、1,024 个 Long Task 和每个交互标签 1,024 个耗时样本，超限时压缩旧样本，长时间挂数不会因观测工具自身持续增长内存。

上一版真实浏览器基线（非当前终验）在 `9,000` 节点、`8,999` 连线且鹰眼开启时独立执行两批、每批 40 次普通组件拖入，各去除前 5 次预热后共保留 70 个有效样本。第一批同步/DOM 提交/下一动画帧 P95 分别为 `0.3ms`、`5.3ms`、`14.7ms`，第二批分别为 `0.4ms`、`5.7ms`、`14.3ms`；70 次新增全部立即成为当前选中对象。这些数字只作旧版对照，本轮仍须重新执行浏览器终验。这里的“零延迟”指无可感知等待，不代表物理 `0ms`。非 UI 基准中，10,000 节点空间索引构建约 `9.61ms`，600 次视口查询平均约 `0.058ms`。

正式 6,016 节点图纸构造的完整会话在旧整对象 `structuredClone` 路径中单次约 `193～215ms`。当前实现输出 398 个 `64KiB` Blob chunks；正式复跑的增量编码时间片 P95/P99/最大值为 `4.26ms/4.45ms/4.50ms`，小 envelope clone 为 `3.22ms`，6,016 节点 round-trip 一致。另一独立调度复跑记录 409 个时间片，P95/最大值 `4.32ms/4.68ms`、envelope clone `2.98ms`。这说明整会话克隆长任务已被有界切片替代，不代表 IndexedDB 磁盘完成时间或任何设备上的绝对零延迟。

正式 `sacada测试.json` 为 `36,037,698 bytes`、6,016 节点、0 个非空 `dataKey`；旧主线程单次基线的 Node 文件读取为 `70.64ms`、`JSON.parse` 为 `177.78ms`，两者只属于打开阶段。当前图纸字符串已由 `projectJson.worker.js` 解析并保留主线程故障降级。以下浏览器挂数数字同样属于上一版基线（非当前终验）：当时没有修改正式文件，只在内存临时副本中逐节点绑定 6,016 个唯一键并按 `500ms` 全量刷新。编辑态连续采样 `97.3s`，帧间隔 P95 为 `14.1ms`、Long Task 为 `0`，406 个可视运行值持续收敛，文字输入到下一帧为 `2.2ms`，拖入组件、属性修改和建立连线均成功。原始尺寸预览稳态采样 `34.6s`，P95 为 `14.2ms`、Long Task 为 `0`，598 个运行值可见且抽样 `40/40` 发生变化；自适应预览采样 `43.3s`，P95 为 `14.1ms`、Long Task 为 `0`，Canvas 非白屏且像素哈希随数据刷新变化；原生全屏采样 `39.9s`，P95 为 `14.2ms`、Long Task 为 `0`，`document.fullscreenElement` 为 `preview-overlay`，运行值抽样 `40/40` 变化且无错误。当前仍需独立终验两组目标：编辑态要求画图、连线、属性、历史和接数立即反馈；预览态要求原始尺寸、自适应和原生全屏分别非空、图层与运行值正确且流畅，自适应还要覆盖纯 Canvas、安全有界尾段 hybrid、请求像素比、正常等待仅保留视口 DOM、Canvas 不适用/失败后的完整 DOM、失败先原尺寸后 `dom-fit`、图片事件合并、隐藏 surface 暂停和 Canvas context 故障回退，原始尺寸及全屏要确认无用 Canvas surface 已释放。这里的“零延迟”只表示用户无可感知等待且操作对象立即可继续编辑，不承诺浏览器调度、屏幕刷新、网络或后端传输的物理 `0ms`；首次 Vue 挂载、单屏可见复杂度和动画数量仍需在目标设备验收，具体边界参见性能说明文档。

新的源绑定性能验收另行构造 6,016 个组件共享 128 条唯一 JSONPath，检查延迟索引重建不会在调用栈同步扫描全部组件、同一快照 revision 每条路径只求值一次、连续快照以最新版本为准，并要求每个构建与派生切片保持在单帧预算内。该场景与上段 6,016 个唯一运行键的通用发布验收相互独立，最终实测数字记录在问题清单对应变更项中。

## 6. 基本操作

1. 在左侧“图纸”页新建图纸，或选择已有图纸进入编辑；需要移除图纸时使用对应卡片的删除按钮。
2. 从左侧“组件”或“我的”拖动组件到画布，也可以双击普通组件添加。“直线”继续从“基本形状”添加；线段必须从独立“线段”分类拖到画布，以松开位置建立第一个节点。较大的起点锚点可在继续落点前或绘制过程中拖动精调，拖动不会新增节点；开启吸附时按住 `Alt` 可临时自由拖动。之后依次单击多个点，相邻两点会立即连成直线，画布双击或按 `Enter` 把全部点完成为一个组件并切回选择。组件库单击或双击不会启动线段；取消或完成后锚点消失，若要画下一条必须重新拖拽。选择顶部“铅笔”后，可从画布空白处、已有组件内部或边缘、锁定组件和已有铅笔线稿上方直接起笔；每次抬起后线稿转为普通组件，铅笔保持激活以便连续绘制。
3. 在选择工具下拖动空白区域框选组件；使用 `Alt + 左键`或鼠标中键拖动画布，使用滚轮缩放。需要防止误平移和缩放时点击右下角图钉固定画布。单击节点后拖动主体移动，极小组件可从本体周围的透明命中区拖动；拖动边角手柄缩放，拖动顶部圆形手柄旋转。
4. 按住 `Ctrl`（macOS 为 `Cmd`）或 `Shift` 并左键单击可逐个增加或移除组件，按住修饰键框选可追加一批组件。形成多选后可直接拖动任一已选成员整体移动，随后点击顶部“组合”、右侧“组合为组件”或右键同名命令。组合后拖动统一选框的角手柄会保持整体宽高比，左右边中手柄只拉宽或压窄，上下边中手柄只拉高或压低；拖动顶部手柄整体旋转，点击“取消组合”恢复独立节点。
5. 右键单个节点、多选节点或组合后选择“添加为我的”，在弹窗中确认缩略预览并设置名称，再从“我的”分类拖拽或双击生成独立副本。
6. 右侧“属性”面板根据组件分类编辑基础属性、文字、图像、样式和类型专属数据；文本组件可在“文字排布”中切换横向或竖向，内容中的连续空格会原样显示；表格可点击摘要打开完整数据面板，并在面板中选择矩形区域进行合并或拆分。
7. 双击画布中的表单组件进入就地交互；点击顶部“预览”可在无编辑框干扰的状态下操作全部表单控件，并可从预览导航栏进入或退出全屏。
8. 点击顶部工具栏末尾独立分组的“数据源”统一建立、保存和测试连接；返回画布后单选组件，进入右侧“通信”，选择参数、数据源和 JSON 字段/JSONPath，核对解析值与类型后点击“建立绑定”。只选择字段不会自动绑定，可在已连接项中更换或解除。
9. 在“我的”页确认当前工作空间；点击顶部“保存”写入当前激活图纸，需要指定其他目录时使用“另存为”。顶部“打开”可选择项目图纸目录中的文件，也可打开其他位置。

## 7. 运行状态检查

启动后依次检查：

1. 页面显示顶部工具栏、左侧组件库、中央画布和右侧属性面板。
2. 浏览器开发者工具 Console 无错误。
3. 拖入组件后可以移动、缩放和旋转。
4. 空白区域正向、反向拖动均可框选节点；`Ctrl/Cmd/Shift + 左键`可逐个增减多选，按住修饰键框选可追加选择。顶部组合按钮常驻可见，多选后顶部、右侧属性栏和右键菜单均可执行组合；多选和组合统一选框可整体移动、角部等比例缩放、横纵独立拉伸和旋转，属性栏宽高可分轴修改。变换后成员内容不得错位或重叠，成员角度保持，取消组合后节点恢复独立编辑。
5. 预览模式中的表单控件可以操作，风机、管道、仪表等动画持续运行，进入/退出全屏按钮与 `Esc` 行为正确。
6. 表格标题、表头、单元格、逐列精确像素宽度、表头高度、统一或逐行高度和样式修改可以立即显示；长文本自适应/缩略查看及横向、纵向、矩形合并和拆分在编辑与预览中一致。
7. 顶部不存在“文件”按钮；“打开”“保存”和组件库展开/收起总开关行为正确。
8. 本地服务启动后项目根目录存在 `图纸库/`；新建两张图纸后可分别编辑、切换和删除会话，保存只更新当前激活图纸。“打开”列表可取消或确认删除图纸库文件，删除按钮不会触发打开，旧 ETag 不能误删新版本。模拟删除失败且刷新列表过滤目标时，会话仍保持文件身份；只有 DELETE/HEAD 明确 `404` 才解绑。未保存图纸与库内文件同名时显示“同名冲突”，两个未保存会话指向同一目标时显示“同名目标”，两者都显示完整规范化保存路径。
9. 保存后的文件可重新打开并完整恢复画布组件、“我的”模板、画布尺寸/样式和连线设置；即使同名图纸的内存会话被临时修改，重新从顶部“打开”选择文件也必须以磁盘 JSON 为准。首次保存同名文件应返回 `412`、提示同名冲突且不覆盖原文件；旧 ETag 保存也返回 `412`，但应提示版本冲突。旧修订不能覆盖或误删新修订。用较小的 `TC2D_MAX_DRAWING_BYTES` 测试替身覆盖单图列表/打开/保存冲突校验/删除读取和 `PUT`：等于上限可用，超限文件列表忽略、直接打开及请求返回 `413`，且调小限制不能命中旧 metadata 缓存。再建立至少 4 个工作空间和多张图纸往返切换，确认完整内容、历史和文件身份从 IndexedDB 恢复；禁用 IndexedDB、模拟句柄克隆失败或让旧并发保存迟到时，最新脏会话不得被 LRU 淘汰，localStorage 兼容副本可以因体积过大而不存在。
10. 单个组件和组合均可添加到“我的”，拖拽或双击后生成独立节点与内部连线；保存并重新打开图纸后模板仍存在。
11. 切换到铅笔后分别从空白画布、普通组件内部、锁定组件和已有铅笔线稿内部起笔，均能生成位于原对象上方的新铅笔组件，且不会误触移动、缩放或解锁。
12. “直线”仍在“基本形状”，“线段”单独成类；组件库单击和双击均不启动线段，只有把卡片拖到画布才以落点建立起点。起点以较大锚点显示，继续落点前和绘制过程中均可拖动；拖动只能更新第一个节点，不得增加节点，网格吸附与按住 `Alt` 临时取消吸附都应生效。第二个及后续落点应立即显示新的相邻直线，画布双击或 `Enter` 后只生成一个完整组件；完成、`Esc`、右键取消以及 `Backspace` 删到零点均切回选择并移除锚点，下一条必须重新拖拽。首尾箭头可独立设置，预览与鹰眼路径一致。
13. 文本内容输入“甲    乙”时，编辑画布和预览应保留四个空格形成的长间隔；切换竖向后字符保持正向、空格保留纵向间隔，对齐文案改为顶部/居中/底部。鹰眼和“我的”缩略图应同步竖排，保存重开后 `textLayout` 不丢失，旧图纸仍为横排。
14. 常用大型“我的组件”或剪贴板包预热后拖入应立即发布并可编辑；冷包应立即出现目标占位框，准备期间页面仍可操作，完成后一次性出现全部节点和内部连线，不得显示半提交实体。
15. 选中超过 128 个节点后移动、缩放和旋转，指针阶段应立即显示组合框反馈；提交期间透明屏障阻止第二条命令，完成后节点、关联连线、图层、撤销和重做结果一致。禁用 Worker 的降级环境同样不得出现单帧全量卡顿。
16. 分别验证两类大数据场景：在 6,016 个组件共享 128 条源 JSONPath 并连续发布快照时，索引按帧建立且只派生最新 revision；在正式图纸的内存临时副本为 6,016 个节点绑定唯一运行键并持续刷新时，拖入、文字输入、属性修改、连线和 Undo/Redo 仍可立即继续。运行值 Canvas 还要验证每 RAF `1 × 512`、重复 ID、整数批边界空终批、sparse/dense 切换、私有工作面、条带 seed、dense 重放和大量时间节点 dense 入口。循环对象、抛错属性、异常代理、超大数组和 BigInt 的显示应有界且不产生控制台错误，正式图纸文件本身不得被压测修改。
17. 编辑态先验证四类交接：大图打开时完整私有运行 bundle 按默认 `4ms` 多片构建，旧任务可取消且完成前不替换活动索引；首屏超过 `128` 个节点时按 `8/64` 预算渐进挂载且完成后全部可编辑；普通倍率视口超过 `1,024` 条边时 Canvas 只绘制边，节点/线稿 DOM 完整，SVG 活动边最多 `128` 条且 edge-only 不保留无用双离屏面；高出度节点拖动不枚举全部边，松手后再以独立 `2ms` 私有索引任务原子收敛。边数组和空间查询 cursor 都要在索引 `entries` 达到 `2,048` 时进入 Worker，cursor 在同一时间片尽量组成 `512` 条命令；模拟 start/batch/finish 任一阶段 8 秒失联后，必须先重放 `task.edges` 再继续剩余 cursor，结果无遗漏、无重复。随后分别检查原始尺寸、自适应和浏览器原生全屏：页面非空、实体与图层完整、运行值继续变化；原始尺寸和全屏保留表单、按钮、视频、时间及 CSS 动画，DOM ready 后不再保留无用 Canvas surface；自适应 Canvas 非白屏且随运行值更新，纯静态时不挂 DOM。存在 live 节点时，从最高层向下最多 `24` 个条目应形成覆盖全部 live 节点的完整尾段，且尾段不超过 `16` 个 node/`128` 成本；满足时由持久 live plane 挂载整个尾段，包含其中的静态 node/drawing，Canvas 通过两组排除 ID 只画下方前缀，否则回退完整 DOM。edge、node、drawing 不得重复。切换计划时只接受匹配 `renderPlanKey/excludedNodeIds/excludedDrawingIds`、freshness 和请求像素比的完整帧；正常 Canvas 等待只保留视口 DOM，Canvas 不适用或失败才请求完整 DOM，失败时先显示原尺寸 DOM，完整渐进挂载 ready 后再切换 `dom-fit`。缩小目标集合时陈旧 DOM 必须立即释放，同 ID 使用最新引用，缺失节点数组原地增长且批量倍率按实际提交耗时在 `1–16` 间自适应。full/runtime/geometry 可见提交必须保持 union clip 单次 copy，提交异常前不得预清空；模拟 Canvas context 丢失/不可用时应立即回退 DOM 且页面非空。关闭/原始/全屏释放 committed plan，漏失 `fullscreenchange` 时 resize/focus/visibilitychange 能校准状态。编辑态和三种预览均应在前台标签页分别达到 rAF P95 `<16.7ms`、Long Task `=0`，不能用其中一组结果替代另一组。
